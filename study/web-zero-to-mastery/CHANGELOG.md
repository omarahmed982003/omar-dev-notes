# سجل تحسين المنهج

## 1.1 — 2026-10-21

طلب الطالب تنفيذ المراجعة التربوية بعد تقسيم المنهج إلى ملفات مستقلة. هذا سجل تحرير فقط؛ ليس دليل دراسة أو نجاح.

### التغييرات المقصودة وحدودها

- تفصيل كل جزئية إلى checkpoints ودروس فرعية بأهداف ومتطلبات وتجارب وتمارين ومعايير قبول، مع الحفاظ على أسماء الملفات وأرقام النقاط الأصلية. الإضافات المحلية لها IDs جديدة عند الحاجة.
- إضافة إدخال CLI وتنظيم PHP متعدد الملفات وتمهيد callbacks، وضبط ترتيب Arrays/foreach. التواريخ والتوطين يأتيان بعد أساس الكائنات.
- تأسيس الشبكة ثم تعميقها داخل الموضوع نفسه؛ بوابة تأسيس تتيح HTML، وبوابة تعميق قبل النشر تمنع إخفاء العمل المؤجل.
- SQL bridge محلي واضح بدل إلزام المبتدئ بإنهاء Storage/Optimizer قبل معاملة بسيطة. المناهج القديمة مراجع وامتدادات لا شروط إكمال شاملة.
- OOP أساسي مناسب لدخول Laravel؛ الدمج المتقدم بعد تقديم ORM والـ Jobs والـ Policies، لا قبلهما. كتالوج patterns و Reflection امتدادان معلنان.
- حماية حساب وجلسة وبيانات المنتج قبل نشره، مع إبقاء OAuth والهوية الموزعة في عمق اختياري له متطلبات؛ لا تخفيف لمعايير الأمان الأساسية.
- Warehouse/Lakehouse تخصص بيانات اختياري، لا شرط لـ PHP Runtime. تمهيد تشغيل Docker قبل Redis، وعمق بناء الصور والتشغيل في 18.
- مختبرات queue failures و worker lifecycle و idempotency، ووحدات واضحة للحاويات و Cloud و CI/CD و Observability و SRE.
- فصل خوارزميات التطبيق عن مختبر التوزيع داخل 19، والتمييز بين تعلم المفهوم واستعماله في تصميم 20، دون نسخ درجات.
- إتاحة Full-stack بعد 7 و 11، وتحديد فرع مختار و Applicable IDs بدل اشتراط نجاح فرعين متنافيين.
- التشخيص 0.1 واختيار 21.1 لهما إغلاق إداري بلا درجات نجاح مصطنعة. باقي المهارات تتطلب 80% وأدلة وإصلاح العيوب الجوهرية.
- تحديث ملفات التقدم بموضع الدرس الفرعي وآخر تمرين والخطوة غير المكتملة، دون منح Passed أو اختلاق جلسة. ملفات تقدم المسارات القديمة لا تتغير.

### التحقق

فحوص البنية في `scripts/verify-web-curriculum.mjs` تتحقق من أزواج الملفات، وتغطية IDs الأصلية، وتطابق الدروس مع جداول التقدم، والروابط المحلية وحقول تسليم السيشن. الخيار `--expect-not-started` يرفض نتائج نجاح أو درجات رقمية مسجلة أثناء مجرد التحرير.

اختبارات `scripts/verify-web-curriculum.test.mjs` تختبر أداة الفحص نفسها بأمثلة صحيحة وأخرى ناقصة أو مكررة أو ذات تقدم مصطنع. هذه الفحوص لا تثبت جودة كل درس مكتوب مستقبلًا، ولا تدّعي تشغيل مختبرات PHP/Laravel/Docker المذكورة في الخطة.

تغيير 1.1 يخص ملفات الدراسة وأداة تحقق لها؛ لا تعديل جديد لصفحات الموقع، ولا حاجة لبناء Astro بسبب هذه الملفات الخاصة وحدها. لا commit أو push ضمن هذا الطلب.

### نتيجة تحقق هذا التعديل

- 23 زوجًا من المنهج والتقدم، و 153 checkpoint محلية تتضمن 150 الأصلية محفوظة، و 314 درسًا فرعيًا لها صفوف متابعة مطابقة في المعرف والعنوان.
- 217 رابطًا محليًا فُحصت أهدافها، دون روابط مفقودة في الملفات المشمولة.
- 8 اختبارات ناجحة لأداة الفحص والتنسيق، تشمل رفض حذف/تكرار IDs أو تسجيل تقدم مصطنع وحماية الكود والروابط عند تنسيق المسافات.
- مقارنة SHA-256 لـ 20 ملفًا قديمًا مباشرة داخل study أكدت عدم تغيرها خلال هذا التعديل.
- جميع الحالات الأولية بقيت غير مبدوءة أوغير مختارة؛ لا درجات فعلية ولا جلسات دراسة مسجلة. مختبرات المنهج مخططة، ولم تُنفَّذ كلها كجزء من تحرير هذه الملفات.
