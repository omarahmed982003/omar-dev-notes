# المرحلة 2 — البرمجة باستخدام PHP

الإصدار: 1.1 — 2026-10-21. المتطلبات: بوابة المرحلة 1. نجهز PHP CLI مدعومًا ونوثق النسخة والمسار والإضافات المطلوبة فقط؛ الأمثلة صغيرة ومن دون Laravel. كل checkpoint ومختبره المستقل يتطلبان دليلًا و 80% وفق القواعد المشتركة.

### 2.1 — أول ملف PHP وتشغيله

المتطلبات: 1.3 و 1.7. النتيجة: يحفظ ملفًا صحيحًا ويشغله ويشرح الفرق بين كود الملف والخرج.

#### 2.1.a — الملف والـ CLI

التسلسل: تحقق من `php -v` ومسار executable ← ملف و PHP tags ← `echo` ← comments و statement ← تشغيل من terminal. المختبر: رسالة باسم ثابت؛ المتوقع نفس الرسالة دون ظهور source في الخرج، مع الاحتفاظ بالأمر ومكانه.

#### 2.1.b — ثلاث طرق لاختلاف المتوقع

التسلسل: syntax error يمنع التحليل، خطأ أثناء التنفيذ، ثم logic error يعطي خرجًا غلطًا؛ نعرض مثالًا واحدًا كل مرة. الغلط: نجاح التشغيل يثبت صحة الحل. تمرين مستقل: يصلح ملفًا قصيرًا ويعيد تشغيله ثم يشرح سبب الخلل؛ دليل source و expected/actual ورمز الخروج.

### 2.2 — القيم والمتغيرات والإدخال الأول

المتطلبات: 2.1. النتيجة: يتتبع assignment ويستقبل قيمة نصية من المستخدم دون افتراض أنها رقم.

#### 2.2.a — أسماء وأنواع وحالة

التسلسل: قيمة ← متغير ← إعادة assignment ← اسم معبر ← `var_dump` ← constants البسيطة؛ value مقابل reference كملاحظة آمنة، لا aliases معقدة الآن. المختبر: نسخ قيمة عددية ثم تغيير النسخة؛ المتوقع تفسير بقاء الأصل، لا حفظ شكل الخرج فقط.

#### 2.2.b — أول stdin

التسلسل: stdin مقابل stdout ← قراءة سطر باستخدام `fgets(STDIN)` ← نهاية سطر/EOF ← الفرق بين الإدخال والناتج. الغلط: أي إدخال يبدو رقمًا صالح لحساب المال، أو `readline` متاح في كل تثبيت. تمرين مستقل: يقرأ اسمًا ويعرض تحية، ويشرح حالة نهاية الإدخال؛ التحقق التفصيلي بالأرقام والشروط في 2.3–2.6، لا ندعيه مبكرًا.

### 2.3 — الأرقام والحساب وحدود الدقة

المتطلبات: 2.2. النتيجة: يحسب مبلغًا بوحدات صحيحة ويفسر لماذا اختيار النوع جزء من صحة الحل.

#### 2.3.a — الحساب والتوقع

التسلسل: integers/floats ← arithmetic/operators ← precedence والأقواس ← القسمة والباقي ← حدود overflow والدقة حسب المختبر. المختبر: فاتورة من سعر بوحدة صغيرة وكمية؛ المتوقع ناتج يدوي مطابق، مع عدم إجراء قسمة على صفر.

#### 2.3.b — شكل الإدخال ليس قيمته

التسلسل: نص عددي مقابل رقم ← casting لا يثبت صحة المدخل ← حالات سالبة/كبيرة/كسرية. الغلط: floats مناسبة تلقائيًا لكل حساب مال. تمرين مستقل: يحسب ثلاث حالات ويختار representation ويشرح حدودها؛ الدليل نتائج وأقواس واضحة، وتأجيل قبول الإدخال إلى التحقق الصريح في 2.6.

### 2.4 — النصوص والبايتات

المتطلبات: 2.3 و 1.2. النتيجة: يبني رسالة ويعالج whitespace و encoding دون الخلط بين character و byte.

#### 2.4.a — بناء وفحص نص

التسلسل: quoting/escaping ← concatenation/interpolation ← `trim` وحدوده ← مقارنة نص فارغ بصفر نصي. المختبر: تحية عربية وقيمة من stdin؛ المتوقع سطر واضح دون مضاعفة newline.

#### 2.4.b — طول ومعنى مختلفان

التسلسل: byte length مقابل عدد أحرف ← UTF-8 ← builtin مناسب وإضافته إن لزم؛ لا نفترض أن cutting bytes آمن للنص العربي. الغلط: escaping داخل PHP يساوي HTML escaping. تمرين مستقل: يفسر طول نص عربي ويحتفظ بالصفر النصي عند تنظيف مدخلات مناسبة؛ دليل input/output وتبرير عدم استعمال أداة غير مناسبة.

### 2.5 — Boolean والمقارنة و null

المتطلبات: 2.4. النتيجة: يتوقع قرار comparison ويمنع الخلط بين بيانات صحيحة وقيم false-like.

#### 2.5.a — مقارنة لها نوع

التسلسل: Boolean ← strict/loose equality ← truthiness ← null/غياب قيمة؛ افحص سلوك النسخة الفعلية. المختبر: جدول توقعات لـ`0` و`"0"` و`false` و`null`؛ المتوقع مقارنة التوقع بخرج موثق وتصحيح التصور.

#### 2.5.b — شروط مركبة قصيرة التنفيذ

التسلسل: AND/OR/NOT ← precedence ← short-circuit يحمي شرطًا لاحقًا. الغلط: `==` بديل آمن دائمًا أو شرط واحد يثبت صلاحية كل البيانات. تمرين مستقل: يكتب شروط قبول مبلغ ونص ويرفض الفراغ دون رفض الصفر المسموح؛ الدليل حالات حدود وتفسير.

### 2.6 — القرار والتحقق قبل الاستخدام

المتطلبات: 2.5. النتيجة: يحول قواعد عمل لقرارات واضحة ويمنع الحساب على إدخال غير صالح.

#### 2.6.a — if وقواعد التحقق

التسلسل: if/elseif/else ← ترتيب الشروط ← parsing منفصل عن validation ← نطاق مسموح ورسالة مفيدة. المختبر: إدخال مبلغ بوحدات صحيحة عبر stdin؛ المتوقع رفض النص الغلط والعدد خارج النطاق، وقبول الحدود المعلنة.

#### 2.6.b — switch و match واختيار واضح

التسلسل: حالات منفصلة ← fall-through في switch ← match كـ expression ومقارنته حسب النسخة. الغلط: default يخفي خطأ إدخال أو تحويل النص لرقم يعالج كل الحالات. تمرين مستقل: قائمة خيارات تستجيب للمقبول وترفض المجهول؛ دليل خمسة inputs بينها فارغ وصفر، وتبرير استخدام الأداة.

### 2.7 — التكرار وإنهاء البرنامج

المتطلبات: 2.6. النتيجة: يتتبع loop ويثبت سبب توقفها. `foreach` مؤجل إلى 2.8 بعد تعريف Arrays؛ نفس IDs محفوظة.

#### 2.7.a — while و for وتغير الحالة

التسلسل: تكرار يدوي ← شرط ← جسم ← تحديث ← while/for ← off-by-one. المختبر: مجموع الأعداد في نطاق صغير؛ المتوقع الناتج المحسوب يدويًا وعدد دورات صحيح.

#### 2.7.b — خروج وإعادة محاولة

التسلسل: break/continue ← sentinel ← EOF ← منع infinite loop وحدود الإدخال. الغلط: continue يتخطى تحديثًا ضروريًا أو زر إغلاق النافذة هو طريقة إنهاء الحل. تمرين مستقل: يقرأ مبالغ حتى أمر خروج معروف ويعالج إدخالًا خاطئًا دون تعليق؛ دليل تتبع وحالة صفر تكرارات وحالة توقف.

### 2.8 — Arrays و foreach و arguments

المتطلبات: 2.7. النتيجة: يمثل مجموعة بيانات ويقرأها بأمان ويستقبل arguments من CLI.

#### 2.8.a — Keys و values والقراءة الآمنة

التسلسل: إنشاء array ← keys/values ← قراءة/تعديل/حذف ← nested data ← missing key/`isset` مقابل `array_key_exists`. المختبر: ثلاثة مصروفات ومفتاح غائب؛ المتوقع نتيجة محددة بلا warning غير معالج. نوضح أنها ليست vector تقليدية في كل تفاصيلها.

#### 2.8.b — foreach و argv

التسلسل: foreach للقيم ثم المفتاح والقيمة ← تجنب iteration بالـ reference في البداية ← `$argv` و`$argc` واسم السكربت ← parsing واختبار العدد والنطاق. الغلط: index صفر هو أول argument للمستخدم أو array فاضية خطأ دائمًا. تمرين مستقل: يقبل أمرًا ومبلغًا، ويرفض missing/extra/invalid arguments برسالة و exit code مناسبين؛ الدليل أوامر وخرج وحالات حدود بلا تعديل نظام التشغيل.

### 2.9 — Functions وتنظيم المسؤوليات

المتطلبات: 2.8. النتيجة: يفصل حسابًا عن إدخال وإخراج ويعيد استعماله ويقرأ callback بسيطًا.

#### 2.9.a — عقد الدالة و scope

التسلسل: parameter مقابل argument ← return مقابل echo ← local scope ← defaults/return types/`strict_types` ← side effects. المختبر: دالة مجموع لا تطبع ولا تقرأ من المستخدم؛ المتوقع نفس النتيجة لنفس البيانات مع كشف نوع خاطئ وفق العقد.

#### 2.9.b — Callable و closure من استعمال صغير

التسلسل: تمرير function كقيمة ← callback ← anonymous/arrow function ← التقاط متغير من scope بأبسط مثال. الغلط: تمرير نتيجة الدالة بدل الدالة، أو return داخل دالة ينهي البرنامج كله. تمرين مستقل: يستخرج دالة تحقق ودالة تجميع، ثم يستعمل callback لتصفية array؛ الدليل اختبارات مدخلات فارغة وصحيحة وغلط، بلا اشتراط patterns أو OOP.

## مشروع المرحلة وبوابة الخروج

برنامج CLI لإدارة مصروفات في الذاكرة: إدخال تفاعلي و arguments، تحقق معلن، إضافة وعرض ومجموع وخروج، functions صغيرة. البوابة: feature جديدة مستقلة، اختبار الصفر والنص غير الصالح والبيانات الفارغة و EOF، وشرح التنفيذ يدويًا و 80%. التاريخ في هذه النسخة نص بسيط معلن الحدود؛ التعامل الحقيقي مع الوقت و UTC و DST في المرحلة 10، فلا نعد هنا بقدرات غير مدرّسة.
