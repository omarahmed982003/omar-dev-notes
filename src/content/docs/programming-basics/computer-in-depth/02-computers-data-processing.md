## افتح صورة وتتبعها

```text
File on storage → Read into RAM → Decode image → Prepare pixels → Display
```

الملف على التخزين يحتوي بايتات، أي مجموعات من 8 بتات. قراءة الملف تنقل بياناته إلى ذاكرة العمل RAM. **فك ترميز الصورة** يحوّل شكل الملف مثل PNG إلى قيم ألوان يفهمها برنامج العرض، ثم تُجهّز النقاط للشاشة. السهم هنا ترتيب عمل مبسط؛ النظام قد يتداخل في تنفيذ مراحل مختلفة.

**سؤال قبل التفاصيل:** لو الملف غير موجود، هل المشكلة في لون البكسل؟ لا؛ القراءة نفسها لم تنجح بعد. هنضع أسماء المقاطعات ونقل البيانات داخل هذه الرحلة، بدل حفظها منفصلة.

## الكمبيوتر نظام لا قطعة واحدة

الكمبيوتر مجموعة طبقات تعمل معًا. **الهاردوير** هو الأجزاء المادية، و**البرمجيات** هي التعليمات والبيانات، و**نظام التشغيل** يدير الموارد ويمنح البرامج واجهة آمنة لاستخدامها. لا ينفذ الجهاز «نية المستخدم»؛ ينفذ تعليمات دقيقة على بيانات ممثلة في صورة بتات.

من المفيد التمييز بين:

- **Data:** قيم خام، مثل بايتات صورة أو درجات طلاب.
- **Information:** بيانات نُظمت أو فُسرت، مثل متوسط الدرجات.
- **Program:** تعليمات محفوظة على وسيط تخزين.
- **Process (عملية: نسخة برنامج تعمل بذاكرة وحالة وموارد):** نسخة عاملة من البرنامج لها ذاكرة وحالة وموارد.
- **Input/Output device:** مكوّن يدخل البيانات أو يعرض/يرسل النتيجة.

## دورة Input–Process–Output–Storage

يمكن تحليل معظم الأنظمة بهذا النموذج:

1. **Input:** قراءة من لوحة مفاتيح أو ملف أو شبكة أو حساس.
2. **Process:** التحقق والتحويل والحساب واتخاذ القرار.
3. **Output:** شاشة أو ملف أو استجابة شبكة أو إشارة تحكم.
4. **Storage:** حفظ النتيجة مؤقتًا في الذاكرة أو دائمًا على SSD (Solid-State Drive؛ وحدة تخزين إلكترونية بلا أجزاء ميكانيكية متحركة)/HDD (Hard Disk Drive؛ وحدة تخزين بأقراص مغناطيسية تدور).

لا تعني الدورة أن كل مرحلة تحدث مرة واحدة. قد يستقبل تطبيق فيديو أجزاء صغيرة، يفك كل جزء، يخزنه في Buffer (مساحة تحتفظ ببيانات مؤقتًا أثناء انتقالها بين طرفين مختلفي السرعة)، ثم يعرضه بينما تصل الأجزاء التالية.

## مثال: فتح صورة وتعديلها

عند فتح صورة، يطلب التطبيق الملف من نظام التشغيل. يقرأ متحكم التخزين أجزاءه إلى RAM (Random Access Memory؛ ذاكرة العمل التي تحمل بيانات وتعليمات البرامج النشطة)، ويفك البرنامج صيغة الصورة باستخدام CPU (Central Processing Unit؛ المعالج الرئيسي الذي ينفذ التعليمات) وقد يستعين بـGPU (Graphics Processing Unit؛ معالج مناسب لعمليات كثيرة متشابهة على بيانات متعددة) للرسم. تحتفظ الذاكرة بالنسخة النشطة، وترسل النتيجة إلى الشاشة. عند الحفظ لا يكفي تعديل RAM؛ يجب كتابة الملف إلى التخزين والتأكد من نجاح العملية.

هذا المثال يوضح أن كلمة «فتح ملف» تخفي تعاونًا بين البرنامج ونظام التشغيل والتعريفات والتخزين والذاكرة والمعالج وبطاقة العرض.

## أين تذهب البيانات؟

- **Registers وCPU caches:** قيم وتعليمات يحتاجها المعالج فورًا.
- **RAM:** مساحة العمل النشطة والسريعة، وتفقد محتواها المعتاد عند انقطاع الطاقة.
- **SSD/HDD:** حفظ طويل المدى بسعة أكبر وزمن وصول أعلى.
- **Network:** نقل البيانات إلى جهاز آخر عبر بروتوكولات متفق عليها.

هذه خريطة عامة. ستدرس المعالج والذاكرة والتخزين ونظام التشغيل كلًا في درس مستقل، ولذلك لا نخلط هنا بين تفاصيل كل جزء بعد ما نثبت الصورة العامة.

## تشخيص العطل من مسار البيانات

إذا كانت النتيجة خاطئة، لا تبدأ بتخمين عشوائي. اسأل:

1. هل وصلت المدخلات فعلًا وبالصيغة المتوقعة؟
2. هل فشل التحقق أو التحويل أو الحساب؟
3. هل الناتج الداخلي صحيح لكن طريقة عرضه خاطئة؟
4. هل حُفظت النتيجة؟ وهل نقرأ النسخة الأحدث أم Cache (نسخة محفوظة لتقليل تكرار القراءة أو الحساب) قديمًا؟
5. هل حدث فشل جزئي في القرص أو الشبكة أو الذاكرة؟

## قِس السؤال المناسب

**Latency (زمن انتظار عملية واحدة) — زمن الاستجابة** مدة انتظار عملية واحدة، و**Throughput (كمية عمل منجزة في مدة) — معدل الإنجاز** مقدار البيانات أو العمل خلال وقت. ألف ملف صغير قد يتأثر بكلفة فتح كل ملف، وملف كبير متتابع قد يتأثر بمعدل نقل البيانات. نفس حجم البيانات الكلي لا يفرض نفس زمن الانتهاء.

**Interrupt — مقاطعة** إشعار من جهاز للمعالج بدل سؤاله المستمر؛ السؤال المستمر اسمه polling. **DMA (Direct Memory Access؛ نقل بيانات بين جهاز والذاكرة من غير نسخ المعالج لكل بايت)** نقل بيانات بمساعدة وحدة مخصصة بدل نسخ المعالج لكل بايت. البرنامج ما زال يحتاج تهيئة وتنظيمًا للوصول.

**تدريب وحل:** نقل ألف ملف كل منها 1 kB مقارنة بملف واحد 1 MB يعني نفس مليون بايت، لكن عدد عمليات فتح الملفات مختلف. سجّل الزمن وعدد العمليات ومعدل النقل، ولا تختزل التشخيص في سرعة CPU. للتذكير: kB=1000 بايت، وKiB=1024؛ MB مليون بايت، وMiB=1048576.
