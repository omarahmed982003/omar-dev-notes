## عنوانان لنفس البيانات

**العنوان الافتراضي** رقم يستخدمه البرنامج داخل مساحة عناوينه، و**العنوان الفعلي** مكان يقابله في الذاكرة. النظام والمعالج يترجمان بينهما. افترض أن الذاكرة مقسمة لصفحات4096بايت: العنوان5000 يعني الصفحة1 والباقي904 من بدايتها. لو موجودة في الإطار7 فعليًا، نصل إلى `7×4096+904=29576`.

```text
Virtual: page 1 + offset 904 → page table: 1 maps to 7 → Physical: frame 7 + offset 904
```

**Page table — جدول صفحات** يحفظ الربط، و**offset — إزاحة** مكان البايت داخل الصفحة. ده حجم صفحة افتراضي للتجربة، مش قاعدة لكل جهاز. **جرّب:** العنوان4096 إزاحته0؛ والعنوان4095 في الصفحة0 وإزاحته4095.

## ما RAM؟

RAM (Random Access Memory؛ ذاكرة العمل التي تحمل بيانات وتعليمات البرامج النشطة) تخزين سريع متطاير يحمل الكود والبيانات النشطة. CPU (Central Processing Unit؛ المعالج الرئيسي الذي ينفذ التعليمات) لا يتعامل معها كقائمة متغيرات؛ يقرأ ويكتب عناوين، غالبًا عبر Cache (نسخة محفوظة لتقليل تكرار القراءة أو الحساب) Lines. Memory Controller يدير الاتصال بالشرائح، وتؤثر القنوات والتردد والـLatency في Bandwidth والزمن.

## Physical وVirtual Memory

كل Process (عملية: نسخة برنامج تعمل بذاكرة وحالة وموارد) يرى Address Space (مجموعة العناوين التي يمكن للعملية استخدامها) افتراضية خاصة. تقسم الذاكرة إلى Pages (صفحات ذاكرة: وحدات ثابتة الحجم يديرها النظام)، وتترجم MMU (Memory Management Unit؛ وحدة ترجمة عناوين الذاكرة وفحص الوصول) العنوان الافتراضي إلى Physical Frame (وحدة ذاكرة فعلية تقابل حجم صفحة) باستخدام Page Tables (جداول تربط الصفحات الافتراضية بمواقعها أو حالاتها) يديرها Kernel. هذا يوفر Isolation ويسمح بتحميل الصفحات عند الحاجة ومشاركة Pages آمنة بين العمليات.

Page Fault (حدث وصول لصفحة تحتاج تدخل النظام؛ قد يكون تحميلًا عاديًا أو وصولًا غير مسموح) لا يعني Crash دائمًا؛ قد يعني أن Page صحيحة لم تُحمّل بعد. إذا اضطر النظام إلى نقل Pages باردّة إلى Swap (مساحة تخزين قد يستخدمها النظام لإبعاد بعض بيانات الذاكرة عن RAM مؤقتًا) يصبح الوصول أبطأ كثيرًا. Thrashing (انشغال النظام بتبديل الصفحات أكثر من إنجاز العمل) يحدث عندما يقضي النظام وقته في تبديل الصفحات بدل العمل.

## تتبع عنوانًا بدل تخيل شرائح منفصلة

افترض صفحات حجمها 4096 بايتًا. العنوان الافتراضي 5000 يقع في الصفحة رقم1 إذا بدأنا العد من صفر، وإزاحته داخلها `5000−4096=904`. لو جدول الصفحات يربطها بالإطار الفعلي رقم7، فالعنوان الفعلي التوضيحي `7×4096+904=29576`. **Page** وحدة في العناوين الافتراضية، و**Frame** وحدة مقابلة في الذاكرة الفعلية؛ المثال لتوضيح الترجمة، وليس قاعدة أن كل نظام يستخدم هذا الحجم.

**TLB (Translation Lookaside Buffer؛ مخزن سريع لترجمات عناوين الذاكرة)** مخزن سريع لترجمات العناوين. عدم وجود الترجمة فيه لا يعني بالضرورة Page fault؛ قد يجدها المعالج في جدول صفحات صالح. **Demand paging** تجهيز الصفحة عند الحاجة، و**Overcommit** سياسة قد تسمح بحجوزات افتراضية أكبر من الموارد المتاحة فورًا؛ مش ضمانًا بنجاح كل كتابة لاحقًا.
