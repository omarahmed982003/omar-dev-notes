بعد ما قرأت نتيجة بحث ناجحة، هتفرق بين اسم غير موجود وخادم لا يستطيع إكمال البحث، ثم بين إخفاء الاستعلام والتحقق من صحة بياناته.

## إجابة غير موجودة وحماية DNS

**Negative caching — تخزين الإجابة السلبية** معناه حفظ رد أن الاسم أو نوع السجل غير موجود مدة محددة، بدل السؤال نفسه كل مرة. لذلك إضافة سجل جديد قد لا تظهر فورًا لعميل عنده رد سلبي محفوظ.

**DNSSEC (Domain Name System Security Extensions؛ امتدادات توقع بيانات DNS للتحقق من سلامتها ومصدرها)، Domain Name System Security Extensions** يضيف توقيعات لسجلات DNS ليتحقق العميل الداعم من مصدرها وسلامتها عبر سلسلة ثقة. لا يشفّر السؤال والرد. أما **DoH (DNS over HTTPS؛ نقل سؤال DNS وردّه عبر HTTPS)، DNS over HTTPS (Hypertext Transfer Protocol Secure؛ طلبات ويب عبر اتصال محمي بالتشفير والتحقق من هوية الطرف الآخر)** و**DoT (DNS over TLS؛ نقل سؤال DNS وردّه عبر TLS)، DNS over TLS** فيحميان الاتصال بين العميل وخادم الاستعلام بتشفيره. حماية هذا الطريق لا تثبت أمان الموقع الذي أعاد DNS عنوانه.

**تدريب محلول:** اسم له سجل A، لكن سؤال AAAA لا يعيد عنوانًا. نستنتج أن عنوان الإصدار السادس لم يظهر في هذا الاستعلام؛ لا نستنتج تعطل سجل الإصدار الرابع أو الموقع كله. اسأل كل نوع مستقلًا.

لمشاهدة تفاصيل قد تشمل TTL، أي مدة حفظ الإجابة بالثواني، استخدم `nslookup -debug -type=A example.com`. راجع حقول answer، أي الإجابة، لأن أداة الاستعلام قد تعرض أقسامًا أخرى أيضًا. كرر مع AAAA وMX وNS؛ الإجابات والوقت تختلف حسب النطاق وخادم الاستعلام.
