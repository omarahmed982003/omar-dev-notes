في الدرس السابق كررنا خطوات باتباع شرط. دلوقتي عايزين نحسب إجمالي ثلاثة أسعار بعد خصم، من غير كتابة نفس الحساب ثلاث مرات. هنستخدم **قائمة** للبيانات و**دالة** للحساب.

## ابدأ بدالة ورقم واحد

الدالة خطوات لها اسم. `double` اسم اخترناه، و`number` اسم المدخل داخلها. `return` ترجع الناتج لمكان الاستدعاء. احفظ المثال باسم `one-function.html` وشغّله؛ المتوقع 14. بعد كده غيّر 7 إلى 0 وتوقع النتيجة قبل التشغيل.

```html
<!doctype html>
<html lang="en">
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>One function</title>
<pre id="output"></pre>
<script>
function double(number) {
  return number * 2;
}
document.querySelector("#output").textContent = double(7);
</script>
</html>
```

`double(7)` هو الاستدعاء: يضع 7 مكان `number` ويعيد 14. تعريف الدالة لا يشغّلها وحده. دلوقتي افصل السؤالين: الدالة تعمل حسابًا واحدًا؛ القائمة لاحقًا تجمع القيم اللي هنكرر عليها الحساب.

## قائمة بدل أسماء كثيرة

**Array — مصفوفة** في JavaScript تجمع قيمًا مرتبة تحت اسم واحد. هنقول عليها قائمة هنا: `const prices = [10, 20, 30];`. الأقواس المربعة تحدد العناصر، والفاصلة تفصل بينها. ده مختلف عن النص `"10, 20, 30"`؛ النص قيمة نصية واحدة.

**Index — موضع العنصر** يبدأ من صفر: `prices[0]` قيمته10، و`prices[1]` قيمته20، و`prices[2]` قيمته30. عدد العناصر `prices.length` يساوي3؛ الموضع3 مش عنصرًا رابعًا موجودًا، وقراءته هنا تعطي `undefined`، يعني مفيش قيمة معرفة فيه. القائمة الفارغة `[]` طولها0.

## دالة لحساب واحد واضح

**Function — دالة** مجموعة تعليمات لها اسم، تستقبل قيمًا إذا احتاجت وترجع نتيجة إذا كتبنا `return`. تخيّل وصفة خصم: تدخل السعر والنسبة، فتطلع قيمة السعر بعد الخصم.

في `function discountedPrice(price, percent)`، كلمة `function` تعلن الدالة، و`discountedPrice` اسم اخترناه، و`price` و`percent` **Parameters — أسماء مدخلات الدالة**. عند كتابة `discountedPrice(20, 10)` نمرر20 و10؛ دي **Arguments — القيم المرسلة في الاستدعاء**. الحساب20×(1−10÷100) يعيد18.

`return` ترجع النتيجة لمكان الاستدعاء وتنهي الاستدعاء الحالي. تعريف الدالة وحده لا ينفذها؛ الأقواس في استدعائها هي اللي تطلب تشغيلها. المتغيرات والمدخلات المكتوبة داخل الدالة لها **Scope — نطاق استخدام** داخلها؛ اسم `price` هنا لا يصير اسمًا عامًا في الصفحة كلها.

## شغّل المثال كاملًا

أنشئ ملفًا اسمه `lists.html` في مجلد التدريب، والصق الآتي ثم احفظ وافتح بالمتصفح. لو نسيت الخطوات، راجع [إنشاء وتشغيل أول ملف](/programming-basics/computer-fundamentals/08-first-program/).

```html
<!doctype html>
<html lang="en">
<meta charset="utf-8">
<title>Lists and functions</title>
<pre id="output"></pre>
<script>
const prices = [10, 20, 30];

function discountedPrice(price, percent) {
  return price * (1 - percent / 100);
}

let total = 0;
for (const price of prices) {
  total = total + discountedPrice(price, 10);
}

document.querySelector("#output").textContent = total;
</script>
</html>
```

النتيجة **54**: أسعار10 و20 و30 تصبح9 و18 و27، ومجموعها54.

- `prices` تحمل القائمة. `const` تمنع إعادة إسناد الاسم لقائمة أخرى؛ لا تعني أن عناصر القائمة لا يمكن تعديلها.
- `for (const price of prices)` تمر على **قيم** القائمة بالترتيب، مرة لكل عنصر. كل دورة تستدعي الدالة للسعر الحالي.
- `total` يبدأ بصفر، ويتغير بعد كل دورة:9 ثم27 ثم54. استخدمنا `let` لأن قيمته تتغير.
- `document.querySelector("#output")` يجد عنصر الصفحة الذي له المعرّف `output`، و`textContent` تضع الناتج كنص داخله. ده نفس أسلوب العرض في أول برنامج.
- `<pre>` عنصر HTML يحافظ على شكل النص، و`<script>` يحوي تعليمات JavaScript. بقية الغلاف يحدد صفحة وترميز UTF-8 لتمثيل الحروف كبايتات.

## عقد المثال وحدوده

**عقد الدالة** وصف للمدخل المسموح والنتيجة المطلوبة: هنا السعر عدد غير سالب، والنسبة عدد من0 إلى100. المثال التعليمي يستخدم قيمًا ثابتة صالحة، ولا يطبق فحص المدخلات بنفسه. لو أخذتها من مستخدم، لازم تتحقق من نوعها وحدودها قبل الحساب؛ ظهور رقم سالب لا يعني خصمًا صحيحًا.

العمليات الكسرية في JavaScript قد تُقرب؛ بعض الكسور مثل0.1 لا تمثل بدقة تامة بالنظام الثنائي. الأرقام المختارة هنا توضح الفكرة، وفي نظام أموال حقيقي تحدد وحدة العملة وقاعدة التقريب صراحة.

## غيّر قيمة وتوقع الناتج

| التعديل | المتوقع | السبب |
|---|---:|---|
| استبدل القائمة بـ `[]` |0|لا توجد دورة، فيظل المجموع الابتدائي|
| استبدلها بـ `[20]` |18|استدعاء واحد|
| اجعل النسبة0 داخل الاستدعاء |60|لا يوجد خصم|
| اجعل النسبة100 |0|الخصم يساوي السعر|
| نادِ الدالة بسعر−20 |مدخل غير صالح|العقد يرفضه، والكود الحالي لا يفحصه|

**تدريب محلول:** أضف40 للقائمة الأصلية. قيمته بعد الخصم36، فيصبح الإجمالي90. وضع `total = 0` داخل الحلقة خطأ؛ سيصفر مجموع كل ما سبقه وتظهر آخر قيمة فقط.

## راجع فهمك

1. ليه نبدأ الموضع بصفر لكن طول القائمة3؟ الموضع رقم ترتيب يبدأ من0، والطول عدد عناصر؛ آخر موضع لقائمة غير فارغة هو الطول−1.
2. ما الفرق بين تعريف الدالة واستدعائها؟ التعريف يحفظ الخطوات، والاستدعاء يشغلها بقيم محددة.
3. هل الطباعة بديل عن `return`؟ لا؛ عرض قيمة شيء وإرجاعها للحساب التالي شيء آخر. في المثال نجمع القيمة المعادة ثم نعرض الإجمالي مرة واحدة.

بقيت تقدر تجمع بيانات مرتبطة وتعيد استخدام عملية واحدة. اشرح الناتج وغيّر القيم الثابتة، ثم استخدم نفس الأفكار مع قيم يكتبها المستخدم.
