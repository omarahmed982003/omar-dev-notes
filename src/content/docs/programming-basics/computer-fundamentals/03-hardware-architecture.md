هتتعرف على وظيفة المكونات الأساسية من خلال استخدامها، من غير فتح الجهاز أو حفظ مواصفاته.

## تتبّع فتح ملف واحد

```text
SSD/HDD → RAM → CPU → Screen
```

السهم هنا يعني انتقال بيانات أو نتيجة معالجة، مش سلكًا مباشرًا بين كل قطعتين. **SSD** وسيط تخزين إلكتروني، و**HDD** قرص تخزين دوّار؛ يحتفظان بالملف بعد إيقاف الجهاز. **RAM** ذاكرة عمل سريعة تحمل البيانات المستخدمة الآن. **CPU** المعالج الذي ينفذ التعليمات على البيانات. الشاشة تعرض النتيجة بعد تجهيزها.

افتح صورة: الملف محفوظ على التخزين، تُقرأ بياناته للذاكرة، وتنفذ المعالجة اللازمة لعرضه. **اختبر فهمك:** زيادة مساحة التخزين لا تعني تلقائيًا زيادة RAM؛ كل واحدة تحل مشكلة مختلفة.

## ماذا يدخل وماذا يخرج؟

لوحة المفاتيح Keyboard والماوس Mouse أدوات إدخال. الشاشة Monitor والسماعة أدوات إخراج. شاشة اللمس تؤدي الدورين: تعرض الصورة وتستقبل اللمس. الكاميرا تدخل صورة، والميكروفون يدخل صوتًا. في اللابتوب تتجمع أجزاء كثيرة داخل جسم واحد، بينما الكمبيوتر المكتبي قد يفصل الشاشة عن صندوق الجهاز.

داخل الجسم توجد لوحة أم Motherboard تصل المكونات ببعضها، ومعالج CPU (Central Processing Unit؛ المعالج الرئيسي الذي ينفذ التعليمات) ينفذ تعليمات، وذاكرة RAM (Random Access Memory؛ ذاكرة العمل التي تحمل بيانات وتعليمات البرامج النشطة) للعمل الجاري، وتخزين مثل SSD (Solid-State Drive؛ وحدة تخزين إلكترونية بلا أجزاء ميكانيكية متحركة) أو HDD (Hard Disk Drive؛ وحدة تخزين بأقراص مغناطيسية تدور) لحفظ الملفات. الدرسين التاليين يشرحان الفرق بين التنفيذ والعمل الجاري والحفظ.

## وصل جهازًا وافهم وظيفة الوصلة

USB (Universal Serial Bus؛ معيار توصيل أجهزة لنقل بيانات وتوفير طاقة بحسب الدعم) وصلة شائعة لأجهزة مثل لوحة المفاتيح ووحدات التخزين. HDMI (High-Definition Multimedia Interface؛ وصلة رقمية للصورة والصوت) وصلة شائعة للصورة والصوت إلى شاشة. تشابه شكل بعض الوصلات لا يضمن نفس القدرات؛ لا تضغط قابسًا لا يدخل بسهولة، وراجع دليل الجهاز عند عدم وضوح الوظيفة. بعض الأجهزة تحتاج شحنًا أو مصدر طاقة لكي تعمل.

Driver «تعريف الجهاز» برنامج يساعد نظام التشغيل يتعامل مع القطعة. غالبًا النظام يجهزه تلقائيًا. لو احتجت تعريفًا، استخدم مصدر الشركة المصنعة؛ لا تحمّل برنامجًا مجهولًا يعد بإصلاح كل التعريفات.

## شخّص من السلوك

لو صورة الجهاز موجودة لكن الصوت غائب، لا تبدأ بحذف ملفاتك. افحص كتم الصوت ومخرج الصوت المختار والسماعة. لو لم تظهر صورة أصلًا، افحص تشغيل الشاشة واختيار مدخلها والوصلة. دي خطوات لفهم موضع المشكلة، مش ضمان تشخيص كل عطل.

**تدريب:** اكتب ثلاث قطع تستخدمها وحدد هل تدخل بيانات أو تخرجها أو تحفظها. حل ممكن: لوحة المفاتيح إدخال، الشاشة إخراج، وحدة التخزين حفظ. هل الشاشة هي الكمبيوتر كله؟ لا؛ عرض النتيجة جزء من منظومة أكبر.

لا تحتاج شراء قطعة جديدة أو معرفة سرعة كل منفذ لبدء البرمجة. يكفي أن تميز وظيفة كل جزء وتستخدم جهازك الحالي في التجارب.
