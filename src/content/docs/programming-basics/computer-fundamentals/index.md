- دورة الجلب وفك الترميز والتنفيذ داخل المعالج Fetch–Decode–Execute.
- الذاكرة الهرمية: Registers وCache وRAM والتخزين.
- دور نظام التشغيل في العمليات والملفات والذاكرة والأجهزة.

- تمثيل النصوص عمليًا باستخدام Unicode وUTF-8.
