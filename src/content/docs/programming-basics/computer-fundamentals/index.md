يشرح هذا القسم مكوّنات الكمبيوتر ودورة معالجة البيانات، وكيف تمثّل الأجهزة الأعداد والنصوص، وما الفرق بين لغة البرمجة والخوارزمية والبرنامج. ثم ينتقل إلى مجالات التقنية وأدوات الذكاء الاصطناعي ونظام التشغيل والطرفية والملفات وGit.

## خريطة الدروس

1. [**خريطة التعلّم وقواعد الدراسة**](./01-learning-roadmap/) — ترتيب الدراسة، التعلم النشط، المراجعة، كتابة الملاحظات، وقياس التقدم.
2. [**الكمبيوتر والبيانات ودورة المعالجة**](./02-computers-data-processing/) — أجهزة الإدخال والإخراج، CPU وRAM والتخزين، ودورة Input–Process–Output–Storage.
3. [**الثنائي ولغات البرمجة والخوارزميات**](./03-binary-languages-algorithms/) — البت والبايت وتمثيل البيانات، Machine Language وAssembly واللغات عالية المستوى والخوارزمية.
4. [**مجالات التقنية والذكاء الاصطناعي والعقلية الهندسية**](./04-tech-fields-ai-engineering-mindset/) — تطوير البرمجيات والويب والبيانات والأمن والذكاء الاصطناعي وطريقة التفكير الهندسي.
5. [**نظام التشغيل والطرفية والملفات وGit**](./05-os-terminal-files-git/) — العمليات والمسارات والأوامر الأساسية وتنظيم الملفات وتتبع الإصدارات.
