هتفتح موقعًا وتفرق بين عنوانه والبحث عنه، وتعرف أن الملف المحلي مش موقعًا منشورًا.

## رحلة قصيرة تكفي للبداية

أنت تكتب عنوان صفحة، والمتصفح يعرف مكان الموقع، ويطلب الصفحة، والخادم يرجع بياناتها، والمتصفح يعرضها. **الطلب** رسالة تطلب موردًا مثل صفحة؛ **الرد** الرسالة التي ترجع ببيانات أو سبب تعذر تقديمها. **الخادم** برنامج يرد على الطلبات.

ركّز الآن على الفرق بين كتابة العنوان وظهور النتيجة. أسماء طرق البحث عن العناوين ونقل البيانات تأتي في قسم الشبكات؛ لا تحتاج حفظها لتنجز تجربة فتح الصفحة هنا.

## أربع كلمات تستخدمها يوميًا

الشبكة Network تربط أجهزة لتبادل البيانات. الإنترنت يربط شبكات كثيرة. Wi-Fi وسيلة اتصال لاسلكية بشبكة قريبة؛ الاتصال بالـWi-Fi لا يضمن أن الشبكة نفسها متصلة بالإنترنت. الراوتر Router يربط شبكتك بشبكات أخرى بحسب إعداد الاتصال.

المتصفح Browser تطبيق مثل Edge أو Firefox يعرض صفحات. الموقع Website مجموعة موارد وصفحات. محرك البحث Search engine خدمة تساعدك تجد مواقع؛ مش هو المتصفح، حتى لو ظهر داخل صفحته الأولى. الويب خدمة تعمل على الإنترنت، والإنترنت يستخدم أيضًا للبريد وخدمات أخرى.

## اكتب عنوانًا معلومًا

افتح المتصفح وانقر شريط العنوان في أعلى النافذة. اكتب `https://example.com` واضغط Enter. هذا عنوان URL (Uniform Resource Locator؛ عنوان يحدد موردًا وطريقة الوصول إليه) لمورد؛ الجزء `example.com` اسم الموقع، و`https` يدل على طريقة اتصال مشفرة. الموقع مثال تعليمي، ولا يحتاج تسجيل دخول.

المتصفح هنا عميل Client يطلب موردًا، وخادم Server يستقبل الطلب ويرد ببيانات. لا تحتاج فهم DNS (Domain Name System؛ نظام يجيب عن أسئلة أسماء النطاقات، ومنها عناوينها) وTCP (Transmission Control Protocol؛ نقل بايتات بترتيب مع معالجة الفقد، مع احتمال فشل الاتصال) والشهادات تفصيليًا الآن؛ يكفي تصور الطلب والرد، ومعرفة أن المتصفح يعرض النتيجة.

لو كتبت كلمات بدل عنوان قد ينفذ المتصفح بحثًا. راجع العنوان الذي وصلت إليه قبل تنزيل ملف أو تسجيل الدخول. الاتصال المشفر لا يضمن أن صاحب الموقع أمين. لا تتجاوز تحذير شهادة الاتصال لتكمل تمرينًا؛ توقف وافحص العنوان والوقت والاتصال.

## ملف محلي وموقع على الإنترنت

قريبًا هتفتح `hello.html` من مجلدك. قد يبدأ عنوانه بـ`file:///`؛ هذا ملف على الجهاز، ولا يعني أنك نشرته للناس. فتح الملف للعرض شيء، ورفعه لخادم متاح على الإنترنت شيء آخر. أمثلة البداية تعمل محليًا بعد حفظها، ولا تحتاج خادم PHP (اسم لغة برمجة تستخدم كثيرًا لمعالجة طلبات الويب على الخادم).

**تدريب محلول:** مؤشر Wi-Fi متصل وموقع معين لا يفتح. هل كل الكمبيوتر تالف؟ لا. جرّب موقعًا معلومًا آخر، وراجع كتابة العنوان؛ قد تكون المشكلة في الموقع أو الاتصال الخارجي. لا تغيّر إعدادات الراوتر عشوائيًا.
