بعد قراءة طلب ورد منفردين، نحتاج ربط طلبات المستخدم ومنع تعديل قديم من مسح تعديل أحدث.

## Stateless لا يعني بلا حالة في التطبيق

HTTP لا يتذكر تلقائيًا الطلب السابق. التطبيق يبني الاستمرارية بواسطة:

- **Cookie:** قيمة يخزنها المتصفح ويرسلها وفق اسم الموقع والمسار وقواعد الأمان المحددة لها.
- **Session:** بيانات يحتفظ بها الخادم، مرتبطة غالبًا بمعرّف في Cookie؛ مثل رقم المستخدم الذي سجل الدخول.
- **Token:** رمز اعتماد يرسله العميل، شائع عند تبادل البيانات بين البرامج. ليس كل token JWT (JSON Web Token؛ صيغة رمز تحمل بيانات ادعاءات، وليست كل الرموز من هذا النوع)، وJWT ليس Session بديلًا تلقائيًا.

## مثال PHP

التطبيق اختياري بعد [تجهيز PHP وتشغيل الخادم المحلي](/php/00-lab-setup/). احفظ الكود في `hello.php` داخل مجلد التدريب، وشغّل `php -S localhost:8000` من المجلد. ده ملف كامل يرد على طلب GET، أي طلب قراءة، ويعيد رسالة ترحيب بصيغة JSON.

```php
<?php
declare(strict_types=1);

header('Content-Type: application/json; charset=utf-8');

if (($_SERVER['REQUEST_METHOD'] ?? '') !== 'GET') {
    http_response_code(405);
    header('Allow: GET');
    echo json_encode(['error' => 'Method not allowed']);
    exit;
}

$rawName = $_GET['name'] ?? 'زائر';
if (!is_string($rawName)) {
    http_response_code(400);
    echo json_encode(['error' => 'name must be text']);
    exit;
}
$name = trim($rawName);

echo json_encode(
    ['message' => "مرحبًا {$name}"],
    JSON_UNESCAPED_UNICODE | JSON_INVALID_UTF8_SUBSTITUTE | JSON_THROW_ON_ERROR
);
```

جرّب `curl.exe -i "http://localhost:8000/hello.php?name=Omar"` على Windows، أو `curl` على الأنظمة الأخرى. المتوقع رمز200 وجسم `{"message":"مرحبًا Omar"}`. افتح لوحة Network، أي الشبكة، في أدوات المطور DevTools لمشاهدة الرسالة أيضًا.

`$_SERVER` يحمل معلومات الطلب، و`$_GET` يحمل معاملات الرابط. `??` يستعمل البديل لو القيمة غير موجودة، و`!==` تقارن مع النوع. `header` تكتب حقل رد، و`http_response_code` تختار الحالة، و`json_encode` تحول بيانات PHP إلى نص JSON. `is_string` تتأكد أن الاسم نص، و`trim` تزيل المسافات من طرفيه. `exit` ينهي الطلب بعد رسالة الخطأ. الثوابت في آخر الملف تمنع تحويل الحروف العربية إلى تسلسلات هروب، وتستبدل بايتات النص غير الصالحة، وتطلب خطأ استثنائيًا لو فشل الترميز لسبب آخر.

**اختبر الحدود:** `?name[]=Omar` يرسل قائمة بدل نص، فيُرفض بـ400. طلب POST يُرفض بـ405 ومعه `Allow: GET` لتوضيح الطريقة المسموحة. الاسم غير المرسل يأخذ «زائر». أوقف الخادم بـCtrl+C بعد التجربة.

## اللغة والنسخة والتعديل المتزامن

**Content negotiation — اختيار تمثيل يناسب العميل** يستخدم مثلًا Accept لنوع البيانات، وAccept-Language للغة، وAccept-Encoding للضغط المدعوم. إذا تغير الرد حسب أحد هذه الحقول، **Vary** يحدد الحقول التي يجب أن يميز المخزن المؤقت نسخها.

**ETag — Entity Tag** معرّف لنسخة المورد يرسله الخادم. **If-None-Match** يقول «أرسل المحتوى لو النسخة اختلفت» ويفيد في إعادة فحص النسخة المحفوظة. **If-Match** يقول «نفّذ التعديل فقط لو النسخة ما زالت مطابقة» ويحمي من **Lost update — ضياع تعديل بسبب كتابة عميل فوق تعديل أحدث**.

**تدريب وحل:** عميل قرأ نسخة `"v7"`، ثم عميل آخر غيّرها إلى `"v8"`. الأول يرسل تعديلًا مع `If-Match: "v7"`. الخادم يفحص الشرط وينفذ الكتابة كوحدة لا يتدخل بينهما تعديل آخر؛ عند عدم التطابق يرفض بـ`412 Precondition Failed`، أي فشل شرط مسبق. يرجع العميل يقرأ الأحدث ويقرر كيف يعالج التعارض.
