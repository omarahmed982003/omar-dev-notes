هنبني برنامجًا بخطوات صغيرة: قيم ثابتة، وقرارات ودوال، ثم إدخال المستخدم والنصوص والأخطاء والحفظ، وصولًا لقائمة مشتريات نختبرها.

ابدأ بعد [استخدام الكمبيوتر](/programming-basics/computer-fundamentals/)، أو تأكد إنك تقدر تنشئ ملفًا وتحفظه وتفتحه.


امشِ بالترتيب؛ المثال الجديد يستخدم اللي قبله. بعد المشروع اختار C++ أو PHP، وارجع للرياضيات حسب التمرين. تفاصيل الهاردوير والخوادم مرجع تتوسع فيه بعد الأساس.
