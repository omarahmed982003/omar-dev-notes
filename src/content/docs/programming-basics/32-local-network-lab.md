هنشغّل عميلًا وخادم بيانات على جهازك. **العميل** يطلب، و**الخادم** يرد. كل واحد له منفذ مختلف: رقم يحدد البرنامج المستقبل. نستخدم ملفات كاملة جاهزة، ونغيّر تجربة واحدة كل مرة.

## التجهيز والتشغيل

1. ثبّت Node.js واختبر `node --version` كما في [تجهيز الخادم المحلي](/programming-basics/computer-fundamentals/17-local-server/). لا توجد حزم إضافية تحتاج تثبيتًا.
2. أنشئ مجلدًا جديدًا باسم `network-practice`. احفظ [ملف المعمل الكامل lab.mjs](/examples/network-lab/lab.mjs) فيه باستخدام حفظ الرابط باسم. تأكد أنه ليس `lab.mjs.txt`.
3. افتح PowerShell في المجلد من شريط عنوان مستكشف الملفات، ونفّذ:

```powershell
node lab.mjs
```

4. افتح `http://127.0.0.1:8765/`. تظهر أزرار التجارب. الخادم الثاني على `http://127.0.0.1:8766`. اترك الطرفية مفتوحة؛ كل طلب يكتب سطرًا فيه مساره ورمزه ومدته ومعرّفه.
5. للإيقاف اضغط Ctrl+C في الطرفية. لو المنفذ مشغول أوقف نسخة المعمل السابقة. إعادة التشغيل تصفّر بيانات الإشعارات وعدّاد الطلبات.

## ابدأ برد واحد

افتح `http://127.0.0.1:8766/api/products/1`. المتوقع بيانات دفتر: الاسم Notebook والسعر20 والعملةEGP. افتح أدوات المطور F12 ثم Network، وأعد التحميل. اختَر الطلب لتجد الحالة200، وهي نجاح تقديم الرد. غيّر آخر جزء إلى2؛ الحالة404 وتعني أن المنتج المطلوب غير موجود في المعمل.

لتشوف الرد ورؤوسه في **PowerShell على Windows**، افتح نافذة ثانية ونفّذ:

```powershell
curl.exe -i http://127.0.0.1:8766/api/products/1
```

`-i` يظهر رؤوس الرد قبل محتواه. نكتب `curl.exe` لتشغيل البرنامج نفسه؛ بعض نسخ PowerShell تستخدم `curl` اسمًا مختصرًا لأداة أخرى. على macOS أو Linux استخدم `curl` بدل `curl.exe`.

## خريطة التجارب

| التجربة | المسار أو الزر | الدليل المتوقع |
|---|---|---|
| خادم واحد | `/api/products/1` على8766 |200 وجسم JSON |
| وسيط واحد | زر Through one proxy | نفس المنتج؛ رأسان يحملان نفس معرّف الطلب |
| قراءة بين أصلين | زرا CORS | رد يصل في الحالتين، لكن JavaScript لا يقرأ إلا المسموح |
| نسخة مخزنة | `/cache` على8766 | `max-age=2` ووسم نسخة؛ طلب شرطي يعيد304 |
| سؤال دوري | Poll three times | ثلاثة طلبات وثلاثة أوقات |
| بث من الخادم | Receive three events | طلب ممتد يحمل ثلاثة أحداث |
| مسار مفقود | `/missing` على8766 |404 ومعرّف طلب |
| فشل مقصود | `/failure` على8766 |500 ومعرّف طلب؛ خطأ تعليمي متعمد |
| حد طلبات | `/limited` على8766 ثلاث مرات سريعًا | أول اثنين200 والثالث429 في نافذة10ثوانٍ |

المعمل يستمع على جهازك فقط، ويشرح السلوك من غير حسابات أو بيانات شخصية. إعداداته تعليمية؛ لا يمثل خدمة منشورة أو نظام دفع. ملفه كامل ومتاح للقراءة، وكل درس يشرح الجزء المرتبط بتجربته.
