المعمل ده **اختياري بـNode.js**، بيئة تشغيل JavaScript خارج browser؛ استخدامه كأداة مشاهدة مش تغيير للغة أمثلة المسار الافتراضية PHP. لو مش عايز تثبته، اقرأ جدول التجارب تحت كتتبعات مدخل/خرج: `/missing` ينتج 404، و`/failure` ينتج 500، والمنتج الموجود ينتج 200 وJSON. فسّر اختلاف الحالات قبل تشغيل أي كود؛ دي نتائج متوقعة لنموذج المعمل، مش قياسات من جهازك. للتطبيق بـPHP بدل Node، عندك [خادم PHP بنجاح وفشل](/programming-basics/07-server-side-path/) و[معمل الجلسة](/programming-basics/22-http-state-and-updates/).

لو اخترت تشغيل المعمل، هنشغّل عميلًا وخادم بيانات على جهازك. **العميل** يطلب، و**server** يرد. كل واحد له منفذ مختلف: رقم يحدد البرنامج المستقبل. نستخدم ملفات كاملة جاهزة، ونغيّر تجربة واحدة كل مرة.

## معمل اختياري بلغة أخرى: التجهيز والتشغيل

1. ثبّت Node.js واختبر `node --version` كما في [تجهيز server المحلي](/programming-basics/computer-fundamentals/17-local-server/). لا توجد حزم إضافية تحتاج تثبيتًا.
2. أنشئ مجلدًا جديدًا باسم `network-practice`. احفظ [ملف المعمل الكامل lab.mjs](/examples/network-lab/lab.mjs) فيه باستخدام حفظ الرابط باسم. تأكد أنه ليس `lab.mjs.txt`.
3. افتح PowerShell في المجلد من شريط عنوان مستكشف الملفات، ونفّذ:

```powershell
node lab.mjs
```

4. افتح `http://127.0.0.1:8765/`. تظهر أزرار التجارب. server الثاني على `http://127.0.0.1:8766`. اترك الطرفية مفتوحة؛ كل طلب يكتب سطرًا فيه مساره ورمزه ومدته ومعرّفه.
5. للإيقاف اضغط Ctrl+C في الطرفية. لو المنفذ مشغول أوقف نسخة المعمل السابقة. إعادة التشغيل تصفّر بيانات الإشعارات وعدّاد الطلبات.

## ابدأ برد واحد

افتح `http://127.0.0.1:8766/api/products/1`. المتوقع بيانات دفتر: الاسم Notebook والسعر 20 والعملةEGP. افتح أدوات المطور F12 ثم Network، وأعد التحميل. اختَر الطلب لتجد الحالة 200، وهي نجاح تقديم الرد. غيّر آخر جزء إلى 2؛ الحالة 404 وتعني أن المنتج المطلوب غير موجود في المعمل.

لتشوف الرد ورؤوسه في **PowerShell على Windows**، افتح نافذة ثانية ونفّذ:

```powershell
curl.exe -i http://127.0.0.1:8766/api/products/1
```

`-i` يظهر رؤوس الرد قبل محتواه. نكتب `curl.exe` لتشغيل البرنامج نفسه؛ بعض نسخ PowerShell تستخدم `curl` اسمًا مختصرًا لأداة أخرى. على macOS أو Linux استخدم `curl` بدل `curl.exe`.

## خريطة التجارب

| التجربة | المسار أو الزر | الدليل المتوقع |
|---|---|---|
| خادم واحد | `/api/products/1` على 8766 | 200 وجسم JSON |
| وسيط واحد | زر Through one proxy | نفس المنتج؛ رأسان يحملان نفس معرّف الطلب |
| قراءة بين أصلين | زرا CORS (قواعد يطبقها browser للسماح بقراءة response بين origins) | رد يصل في الحالتين، لكن JavaScript لا يقرأ إلا المسموح |
| نسخة مخزنة | `/cache` على 8766 | `max-age=2` ووسم نسخة؛ طلب شرطي يعيد 304 |
| سؤال دوري | Poll three times | ثلاثة طلبات وثلاثة أوقات |
| بث من server | Receive three events | طلب ممتد يحمل ثلاثة أحداث |
| مسار مفقود | `/missing` على 8766 | 404 ومعرّف طلب |
| فشل مقصود | `/failure` على 8766 | 500 ومعرّف طلب؛ خطأ تعليمي متعمد |
| حد طلبات | `/limited` على 8766 ثلاث مرات سريعًا | أول اثنين 200 والثالث 429 في نافذة 10 ثوانٍ |

المعمل يستمع على جهازك فقط، ويشرح السلوك من غير حسابات أو بيانات شخصية. إعداداته تعليمية؛ لا يمثل خدمة منشورة أو نظام دفع. ملفه كامل ومتاح للقراءة، وكل درس يشرح الجزء المرتبط بتجربته.
