# البرمجة كائنية التوجه في PHP

يحوّل هذا القسم الصفحات **71–77** من الملاحظات إلى مسار عملي، مع تصحيح التفاصيل المرتبطة بإصدارات PHP وإضافة أمثلة تصميم قابلة للاختبار.

## خريطة الدروس

1. [الأصناف والكائنات والتغليف](./01-classes-objects-encapsulation/) — Properties وMethods وVisibility وInvariants.
2. [الوراثة وتعدد الأشكال](./02-inheritance-polymorphism/) — is-a وOverride و`final` وComposition.
3. [Traits وإعادة الاستخدام الأفقي](./03-traits/) — `use` و`insteadof` و`as` وحل التعارض.
4. [التجريد والواجهات](./04-abstraction-interfaces/) — Abstract Classes وInterfaces والعقود.
5. [الثوابت وStatic وLate Static Binding](./05-constants-static/) — `const` و`self::` و`static::`.
6. [Constructors وReadonly وDependency Injection](./06-constructors-readonly-di/) — حقن الاعتماديات وكائنات قيمة ثابتة.
7. [Magic Methods وCloning](./07-magic-methods-cloning/) — `__get` و`__call` و`__invoke` و`__clone` و`__debugInfo`.
8. [قائمة مراجعة OOP](./08-review-checklist/) — أسئلة عملية وتمرين شامل لمراجعة التصميم.

:::tip

:::
