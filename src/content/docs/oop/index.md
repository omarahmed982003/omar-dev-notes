# البرمجة كائنية التوجه في PHP

المسار ده يشرح تنظيم البرامج باستخدام الكائنات بصورة عملية، ويبيّن إمتى يساعدك كل أسلوب وإمتى يزود التعقيد من غير فائدة.

## خريطة الدروس

1. [الأصناف والكائنات والتغليف](/oop/01-classes-objects-encapsulation/) — Properties وMethods وVisibility وInvariants.
2. [الوراثة وتعدد الأشكال](/oop/02-inheritance-polymorphism/) — is-a وOverride و`final` وComposition.
3. [Traits وإعادة الاستخدام الأفقي](/oop/03-traits/) — `use` و`insteadof` و`as` وحل التعارض.
4. [التجريد والواجهات](/oop/04-abstraction-interfaces/) — Abstract Classes وInterfaces والعقود.
5. [الثوابت وStatic وLate Static Binding](/oop/05-constants-static/) — `const` و`self::` و`static::`.
6. [Constructors وReadonly وDependency Injection](/oop/06-constructors-readonly-di/) — حقن الاعتماديات وكائنات قيمة ثابتة.
7. [Magic Methods وCloning](/oop/07-magic-methods-cloning/) — `__get` و`__call` و`__invoke` و`__clone` و`__debugInfo`.
8. [قائمة مراجعة OOP](/oop/08-review-checklist/) — أسئلة عملية وتمرين شامل لمراجعة التصميم.

:::tip
OOP ليست تحويل كل شيء إلى class. الهدف حماية القواعد وتجميع الحالة مع السلوك وتقليل الاعتماد بين الأجزاء.
:::
