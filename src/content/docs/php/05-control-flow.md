## المشكلة: قرار واحد ثم تكراره

عندك كشف درجات: 95 تستحق A، و40 تستحق F، و150 لازم نرفضها. بعد كده نكرر القرار لكل طالب. **Control Flow** هو طريق تنفيذ التعليمات؛ **Condition** سؤال نتيجته `true` أو `false`، و**Loop** حلقة تعيد مجموعة تعليمات. ذاكر اختيار الطريق أولًا، وبعدها تتبع التكرار على ورقة. كل برنامج كامل هنا يعمل على PHP 8.0+ في ملف مستقل.

## if وelseif وelse: أول فرع صحيح

**Block** مجموعة تعليمات بين `{ }`، و**Branch** طريق يختاره الشرط. `if` تعني «لو»، و`elseif` «وإلا لو»، و`else` «في باقي الحالات». PHP تختبر من فوق لتحت وتتوقف عند أول فرع صحيح في السلسلة. احفظ `grade.php` وشغّل `php grade.php`:

~~~php
<?php
$score = 75;
if ($score < 0 || $score > 100) {
    $grade = 'invalid';
} elseif ($score >= 90) {
    $grade = 'A';
} elseif ($score >= 75) {
    $grade = 'B';
} elseif ($score >= 50) {
    $grade = 'C';
} else {
    $grade = 'F';
}
echo "Score {$score}: {$grade}", PHP_EOL;
~~~

~~~text
Score 75: B
~~~

`$score` المدخل. `||` معناها «أو»، فنرفض ما دون 0 أو فوق 100. عند 75 الشرط الأول false، ثم شرط 90 false، ثم شرط 75 true. نخزن B ونتجاوز الفروع التالية. `echo` خارج السلسلة، فيعمل بعد أي فرع.

| المدخل | الناتج |
|---|---|
| -1 / 101 | invalid |
| 0 / 49 | F |
| 50 / 74 | C |
| 75 / 89 | B |
| 90 / 100 | A |

**غلط وتصحيحه:** البدء بـ`$score >= 50` يجعل 95 تأخذ C. رتب الحدود من الأعلى للأقل. واستبدال `elseif` بـ`if` منفصلة يسمح لعدة فروع بتغيير النتيجة؛ خلي البدائل في سلسلة واحدة، واستخدم شروطًا مستقلة فقط لما تحتاج إجراءات مستقلة. `>=` يشمل الحد نفسه؛ `>` يستبعده.

## اختصارات اختيار قيمة

`$active ? 'active' : 'paused'` هي Ternary: الشرط، نتيجة الصح، نتيجة الغلط. استخدمها لقيمة قصيرة. `$input['name'] ?? 'guest'` تختار البديل لو المفتاح مفقود أو `null` فقط؛ تحافظ على `0` و`''`. أما `?:` فتستخدم التحويل لمنطقية، فتستبدل `'0'` أيضًا.

`$user?->address?->city` تستخدم Nullsafe: تتوقف عند `null` في سلسلة كائنات، مش عند Exception أو مفتاح Array مفقود. تفاصيل الكائنات في [OOP](/oop/). في HTML ممكن `if (...): ... else: ... endif;` بدل الأقواس، لكن لا تخلط الصيغتين في نفس الكتلة.

## switch وmatch

`switch` تختار `case` حسب قيمة. `break` تمنع الانتقال للحالة التالية؛ استمرار التنفيذ بدونها اسمه **fall-through**. `match` تعبير يعيد قيمة من PHP 8.0، يقارن بالنوع والقيمة `===`، ولا يسقط لفرع آخر. شغّل `status.php`:

~~~php
<?php
$status = '200';
switch ($status) {
    case 200:
        echo "switch: success", PHP_EOL;
        break;
    default:
        echo "switch: other", PHP_EOL;
}
$message = match ($status) {
    200, 201 => 'success',
    default => 'other',
};
echo "match: {$message}", PHP_EOL;
~~~

~~~text
switch: success
match: other
~~~

`switch` تستخدم مقارنة مرنة فتطابق النص `'200'` بالعدد `200`. `match` لا تطابقهما. كل **arm** قيمة ونتيجتها بعد `=>`، وممكن عدة قيم تشترك في نتيجة. بدون تطابق أو `default` يحصل `UnhandledMatchError`. `match (true)` مع شروط مثل `$age < 18` ممكنة للنطاقات، لكن `if` غالبًا أوضح. تحقق من المدخل قبل تحويل نوعه.

## for: البداية ثم الاختبار ثم الجسم ثم الخطوة

**Counter** عداد للدورات، و**accumulator** قيمة تجمع النتائج. احفظ `sum.php` وشغّله:

~~~php
<?php
$total = 0;
for ($i = 1; $i <= 3; $i++) {
    $total += $i;
    echo "i={$i}, total={$total}", PHP_EOL;
}
echo "after: i={$i}, total={$total}", PHP_EOL;
~~~

~~~text
i=1, total=1
i=2, total=3
i=3, total=6
after: i=4, total=6
~~~

`$total = 0` تحصل مرة؛ لو دخلت الجسم المجموع يبدأ من الصفر كل دورة. `$i = 1` تبدأ مرة، ثم `$i <= 3` تُفحص قبل كل دورة. الجسم يجمع ويطبع، و`$i++` تزيد واحدًا بعده. عند 4 نخرج. لا تضع `;` بعد `for (...)` لأنها تصنع جسمًا فارغًا.

| قبل الجسم | المجموع قبله | بعد الجمع | بعد الزيادة |
|---|---|---|---|
| i=1 | 0 | 1 | i=2 |
| i=2 | 1 | 3 | i=3 |
| i=3 | 3 | 6 | i=4 |

قائمة من 3 عناصر مفاتيحها 0 و1 و2، فشرطها `$i < count($names)` وليس `<=`. دورة زيادة أو ناقصة اسمها **off-by-one**. أجزاء `for` اختيارية؛ `for (;;)` لا تنتهي من نفسها. للقوالب `for (...): ... endfor;`.

## while وdo-while: إمتى تفحص؟

`while` تفحص قبل الجسم؛ ممكن تعمل صفر مرة. `do-while` بعده؛ تعمل مرة على الأقل. في `attempts.php` عندنا مدخلات ثابتة عشان نعرف نكرر التجربة:

~~~php
<?php
$replies = ['', '', 'Omar'];
$attempt = 0;
do {
    $input = $replies[$attempt] ?? '';
    $attempt++;
    echo "attempt={$attempt}", PHP_EOL;
} while ($input === '' && $attempt < 3);
echo $input === '' ? "No name\n" : "Hello {$input}\n";

$remaining = 0;
while ($remaining > 0) {
    echo "work", PHP_EOL;
    $remaining--;
}
~~~

~~~text
attempt=1
attempt=2
attempt=3
Hello Omar
~~~

نقرأ عنصرًا ثم نزود المحاولة قبل الاختبار. `&&` تعني إن الشرطين لازم يصحوا: الاسم فاضي ولسه أقل من 3 محاولات. الحلقة الأخيرة لا تعمل. لو هتقرأ بـ`fgets(STDIN)` افحص `false` لنهاية الإدخال. كل Loop محتاجة تقدم وحد خروج؛ مجرد وجود زيادة في مسار لا يضمن إن كل المسارات توصل لها.

## foreach وcontinue وbreak

`foreach` تزور العناصر بدون إدارة فهرس. `continue` تتخطى باقي الدورة الحالية، و`break` تنهي الحلقة. شغّل `scores.php`:

~~~php
<?php
$scores = ['Ali' => 0, 'Mona' => -1, 'Omar' => 100, 'Nour' => 80];
foreach ($scores as $name => $score) {
    if ($score < 0) {
        continue;
    }
    echo "{$name}: {$score}", PHP_EOL;
    if ($score === 100) {
        break;
    }
}
~~~

~~~text
Ali: 0
Omar: 100
~~~

`$name => $score` تقرأ المفتاح والقيمة. الصفر درجة صحيحة؛ Mona تُتخطى، وNour لا تُزار. مع Rows ممكن `foreach ($users as ['id' => $id, 'name' => $name])` لو الحقول موجودة. `break 2` تخرج من مستويين؛ ارسم التداخل قبل استخدامها. `continue` داخل `switch` متداخلة قد لا تقصد بها المستوى الصحيح؛ بسّط التصميم أو حدد المستوى بعناية.

`foreach ($prices as &$price)` تسمح بتعديل الأصل بالمرجع. بعد النهاية تظل `$price` مرتبطة بآخر عنصر: استخدم `unset($price)` فورًا. ابدأ بالتمرير بالقيمة، واستعمل المرجع لما يكون التعديل مقصودًا.
