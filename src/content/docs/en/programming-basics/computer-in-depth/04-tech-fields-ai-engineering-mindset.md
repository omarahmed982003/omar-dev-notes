## Choose a small task with a clear output

Choose **one** before trying another:

| Area | Available tool | Task | Output |
|---|---|---|---|
| Web interface | Text editor and browser | Change the first message and add an input-lesson button | Working HTML and observed result |
| Data processing | Earlier functions and lists | Sum `[10,20,30]` and test empty input | 60 and 0, with explanations |
| Networking | Browser and Wi-Fi exercise | Compare the same page near/far from an access point | Results table and limits of the inference |
| AI-assisted code review | An available assistant, if any | Ask about the discount function; test 0% and 100% claims | Claim, test, result, correction if needed |

A paid account and a four-area week are unnecessary. Judge understanding of output and cause, not the number of tools opened.

## Overview

Technology fields share foundations but differ in problems and tools. Make an informed choice by trying small tasks in several areas rather than chasing the most popular title.

## Core concepts

- Software and web development build user-facing applications and services.
- Data and AI (Artificial Intelligence, systems performing tasks such as prediction or content generation) collect, analyze, and model data for prediction or decisions.
- Cloud and platform engineering focus on reliable operation, deployment, and automation.
- Cybersecurity protects systems, while systems and networking operate infrastructure.
- Embedded systems and IoT (Internet of Things, connected devices exchanging measurements or commands) connect software to sensors and physical devices.

## Worked example

Run a mini exploration: build a web page, analyze a data file, deploy a local service, and control a simulated sensor. Compare the kind of problem you enjoyed.

## Corrections and common mistakes

- AI can help with some tasks, but the benefit depends on the task and user; requirements analysis, verification, and testing remain necessary.
- A degree can help, but it does not replace fundamentals, projects, and communication.

## Explore a field through a concrete problem

**Cloud services** provide remotely managed computing or storage. **Platform engineering** builds internal development and operation tools. An **embedded system** performs a focused task inside a device. **IoT, Internet of Things**, connects devices exchanging measurements or commands. **AI, Artificial Intelligence**, includes models performing tasks such as prediction or text generation; output is not guaranteed correct.

**Worked exploration:** Compare your local price-display page with calculating the mean of ten prices. The first concerns presentation and user interaction; the second concerns what numbers mean and whether data is valid. Record what you built and corrected rather than choosing by a field name.

**Bias** is unwanted systematic variation in results across cases or groups; **evaluation** compares behavior against chosen evidence and expectations. Data quality, privacy, and evaluation criteria matter from the start. An AI coding tool does not improve every person's productivity on every task.
