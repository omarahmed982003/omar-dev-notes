Distinguish a program from the file it opens, and downloading from installing and running. You should already be able to open File Explorer and save text.

## Match permission to purpose

A **permission** allows access to something such as the camera. A calling app requesting it when a call starts has a clear purpose. A calculator requesting contacts does not: decline and investigate the need.

**Decide:** A text editor asks you to select a file, then asks to run as administrator. Are both equally necessary?

<details><summary>Compare your answer</summary>

Selecting a file enables reading it. Administrator access permits broader system changes and is normally unnecessary for editing your own practice file. Connect permission to the task and trusted source.

</details>

## One file, different applications

Notepad edits text. A browser displays pages and executes certain kinds of code. You can open an `.html` file in Notepad to see its source, or in a browser to see the result. A word processor such as Word adds its own formatting; we use a plain-text editor for code.

Open with selects the application used for a file. Opening in an unexpected application does not prove that the file is corrupt. Check the application and extension before changing its contents.

## Three different actions

Downloading transfers a copy to your device. Installing prepares an application and its files to work. Running starts using it. Downloading an installer does not mean the application is installed, and deleting the installer does not usually uninstall the installed application.

Some applications run inside a browser; some run from a folder without a traditional installation. The browser itself is installed software. Existing tools are enough for this introduction; follow the setup lesson when you reach a language requiring another runtime.

## Simple safety decisions

When you need a tool, use its official website or a trusted system store and check the publisher instead of clicking the first Download advertisement. Read permission requests: administrator access permits wider changes, so do not approve without understanding. Updates change a program version and fix problems; save work before an update requiring a restart.

Keep passwords out of practice files and error screenshots. Use different passwords for important accounts and an additional verification method when available. An urgent sign-in message may be deceptive: check the actual address, not just the logo. Do not execute an unknown person’s command merely because they promise to fix your computer.

## Try and explain

Open `note.txt` with Notepad using Open with, edit one word, and save. No new application is needed. Choose the accurate description: “downloaded a file,” “installed an application,” or “opened a file.” You opened an existing file; you did not download or install anything.

**Check yourself:** Does an `.exe` extension or a website’s connection-security indicator prove everything is safe? No. The extension describes handling and encryption protects transport; the file’s source and the organization you deal with still matter.
