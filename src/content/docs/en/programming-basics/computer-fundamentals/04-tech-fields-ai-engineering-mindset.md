Demonstrate practical tool use and explain a small program, then choose a language course instead of treating every advanced topic as a prerequisite.

## Check readiness with your project

Before choosing a language track, demonstrate a function taking input and returning a result, iteration over a list, rejection of a blank name and fractional quantity, a useful failed-read message, and save/reload across reopening. Explain memory data versus the saved copy.

Return to any lesson you cannot explain and make a small change. Readiness means predicting and explaining results, not just calculating or copying code.

## Demonstrate the complete flow

Before the shorter arithmetic review below, finish the [shopping project](/en/programming-basics/computer-fundamentals/16-shopping-project/). Explain why a blank input differs from zero, reject an invalid quantity, save two items, reopen and restore them, and describe what happens when saving fails. Use the project's acceptance table to record expected and actual results. Fixing a bug includes rerunning its failing case.

## One combined task

Create a `readiness` folder inside FirstSteps. Copy values.html (Hypertext Markup Language, a language describing page structure) into it and rename the copy cost.html. Open it in Notepad, set pen price to 7 and quantity to 4, save, and open in your browser. Write the expected result before running.

**Explained solution:** Multiply price by count: 7×4=28. Renaming the file alone does not change its calculation; edit the values inside. If 30 appears, check that you saved cost.html and opened the new location rather than the old copy.

Change quantity to zero and expect zero. Explain where total is calculated and why changing price afterward does not automatically update total. Test rejection of a negative quantity in a copy of conditions.html. These local programs require no Git, server, or internet connection.

## Practical readiness checklist

- Locate the file in its folder and identify its final extension.
- Distinguish editing source from displaying the browser result.
- Save, reload, and confirm both applications use the same file.
- Explain a value, variable, operation, condition, and loop in the examples.
- Compare expected and actual results and fix a small error without random changes.

If saving is difficult, repeat the files lesson; for calculation revisit values; for repetition revisit the loop trace. Passing does not mean mastery of programming; it means readiness for a language course with larger exercises.

## Choose one language course

[C++](/en/cpp/) teaches a language and its compilation tools. [PHP](/en/php/) teaches a language commonly used in web applications. Do not paste JavaScript unchanged into either language: concepts transfer but syntax and runtime differ. Start the selected language’s setup lesson even after successfully running the browser example.

Programming areas include user applications, websites, data analysis, and device control. Tools and problems differ, but inputs, calculations, decisions, and debugging are shared ideas. Try a small project with one language before demanding a permanent specialization choice from yourself.

## When to go deeper

Use [math and problem solving](/en/programming-basics/math-problem-solving/) as exercises require. Study [networking and the web after the basics](/en/programming-basics/networking-next/) when starting a web application, and [computer internals and development tools](/en/programming-basics/computer-in-depth/) when comfortable writing programs.

An AI (Artificial Intelligence, systems performing tasks such as prediction or content generation) assistant can explain an error or suggest a test case, followed by your own verification. Copying an answer does not replace understanding an instruction and predicting its result. Do not share secrets or files you are not authorized to share.

Before continuing, also [practice lists and functions](/en/programming-basics/computer-fundamentals/11-functions-and-lists/): explain why three discounted prices total54, then add a fourth price and predict90.
