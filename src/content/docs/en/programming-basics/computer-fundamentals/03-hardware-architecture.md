Identify basic components through their jobs, without opening the computer or memorizing specifications.

## Follow one file opening

```text
SSD/HDD → RAM → CPU → Screen
```

Arrows show data or processed results, not a direct wire between every pair. An **SSD** is solid-state storage; an **HDD** uses rotating disks. Both retain files after shutdown. **RAM** is fast working memory. The **CPU** executes instructions on data; the screen displays a prepared result.

Open an image: storage supplies its data, memory holds it, and processing prepares display. **Check:** increasing storage capacity does not automatically add RAM; they solve different problems.

## Input and output

A keyboard and mouse provide input. A monitor and speaker provide output. A touchscreen does both: it displays and receives touches. A camera supplies images and a microphone supplies sound. A laptop combines many parts in one body; a desktop may have a separate monitor and system case.

Inside are a motherboard connecting components, a CPU (Central Processing Unit, the main instruction-executing processor) executing instructions, RAM (Random Access Memory, working memory for active program data and instructions) holding current work, and storage such as an SSD (Solid-State Drive, electronic storage without moving mechanical parts) or HDD (Hard Disk Drive, storage using rotating magnetic disks) retaining files. The next two lessons distinguish execution, active work, and saving.

## Connections have purposes

USB (Universal Serial Bus, a device connection standard supporting data and power according to capabilities) commonly connects devices such as keyboards and storage drives. HDMI (High-Definition Multimedia Interface, a digital audio and video connection) commonly carries picture and sound to a display. Similar-looking connectors do not guarantee identical capabilities. Do not force a connector; consult the device guide when its purpose is unclear. Some devices also need charging or external power.

A driver is software helping the operating system communicate with hardware. The system often sets it up automatically. If a driver is needed, use the manufacturer’s source rather than an unknown “fix every driver” application.

## Diagnose from symptoms

If you have a picture but no sound, do not start deleting files. Check mute, selected sound output, and the speaker. If there is no picture, check monitor power, selected input, and cable. These steps narrow the problem; they do not guarantee diagnosis of every fault.

**Exercise:** Name three components and classify input, output, or storage. For example: keyboard—input, monitor—output, storage drive—saving. Is the monitor the whole computer? No; displaying the result is one role in a larger system.

You do not need to buy hardware or know every connector’s speed to start programming. Identify each part’s role and use your existing computer for practice.
