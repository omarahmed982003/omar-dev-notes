Open a program, type in it, and switch between windows. You need a running computer and a signed-in account; on a shared device, use your own account and leave other people’s files alone.

## Two indicators with different jobs

| Approximate shape | What moves? | Try |
|---|---|---|
| `↖` mouse pointer | Follows the mouse and points to a click target | Move over blank space, then a button |
| `Omar│Ali` text caret | A blinking line marking where the next character goes | Click between the names and type a space |

The mouse pointer may become I-shaped over text. That is different from the insertion caret. Clicking elsewhere in the text moves the insertion position.

## Understand the screen

The desktop is the workspace shown after sign-in. An icon is a small image that can open a program, file, or location. A window is an area belonging to an open program; several windows can exist at once. Moving or minimizing a window does not delete the program.

A single click usually selects an item or presses a button. A double-click opens many files and icons. Right-clicking shows choices for that item. On a touchpad, move your finger to move the pointer; use the mouse wheel or scrolling gesture to see content below the visible area.

## Open a text editor

1. Open Start using the Windows key or the taskbar.
2. Search for `Notepad` and open it.
3. Click the writing area, type `My first note`, press Enter, and type `I am learning`.

Enter starts a line in a text editor but may execute an action in another program. The thin text cursor marks where the next character goes; the mouse pointer marks where you click. If characters use the wrong language, switch keyboard language from the taskbar language indicator; Windows+Space is a common Windows shortcut.

## Edit without retyping everything

Drag across a word to select it. Try Ctrl+C to copy and Ctrl+V to paste elsewhere. Ctrl+X cuts; Ctrl+Z undoes an edit; Ctrl+A selects all text. The + in a shortcut means pressing the keys together, not typing a plus character.

Minimize temporarily hides a window on the taskbar; maximize enlarges it; close closes that window. If closing asks whether to save changes, pay attention: the next lesson explains saving. Leave the window open for now.

## Exercise and explanation

Type two lines, copy a word onto line two, and undo once. The new copy should disappear while the original remains. If the original disappeared after pasting, you may have cut instead of copied; undo and repeat with Copy. Do not apply Undo blindly to an unexplained change in another application.

**Check yourself:** Does minimizing Notepad erase its text? No. But visible text is not proof that a file has been saved.
