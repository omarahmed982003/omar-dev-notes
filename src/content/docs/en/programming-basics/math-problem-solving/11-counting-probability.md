Two shirts and three trousers give six combinations: list them first. From counting, distinguish ordering people from choosing a group, then calculate probability with explicit assumptions. First understand sets from the preceding lesson.


## Sequences, counting, probability, and graphs

Arithmetic sequences add a fixed difference, while geometric sequences multiply by a fixed ratio. A recurrence defines terms from earlier terms and must include base cases.

The multiplication principle multiplies the number of available choices at each stage when that count is the same for every preceding choice; it does not require probabilistic independence. Permutations consider order; combinations do not. Probability begins with a sample space and events. Pseudorandom generators are deterministic and ordinary generators must not protect secrets.



## Work through sequences, counting, and randomness

An arithmetic sequence such as 3,5,7,9 adds2 each time; term n, starting at n=1, is 3+2(n−1). A geometric sequence such as 3,6,12,24 multiplies by2; term n is 3×2^(n−1). The caret here denotes a power in plain mathematical text, not an operator shared by every programming language.

A **recurrence** defines a value using earlier values. Fibonacci starts with F(0)=0 and F(1)=1, then F(n)=F(n−1)+F(n−2) for n≥2. Those **base cases** let us calculate 0,1,1,2,3,5; the recurrence alone does not supply a starting value.

The **factorial**, n!, multiplies integers from1 through n; 0!=1. Thus4!=24 arrangements of four different people. Values grow quickly:20! exceeds a32-bit integer. Check the maximum before choosing a bounded numeric type.

A **pseudorandom** sequence is generated by an algorithm from an initial state called a **seed**. The same algorithm and seed reproduce the sequence, which helps repeat a simulation test. Passwords and keys require a generator designed for security; using the current time as a seed is not enough.



**Worked check:** the fourth sequence terms are9 and24. Rounding −2.3 downward gives−3 and upward gives−2. A halfway value such as2.5 depends on the language's rounding rule; do not assume all round functions resolve ties alike.

## Worked sets, counting, and probability

A set contains distinct elements. Let A={1,2,3} represent learners passing test one and B={3,4} test two. Union A∪B={1,2,3,4} means passing at least one, intersection A∩B={3} means both, and difference A−B={1,2} means only the first. The union size is 3+2−1=4: subtract the overlap counted twice.

Choosing a leader and deputy from four people without repetition gives 4×3=12 because roles are ordered. Choosing two members without roles gives 12÷2=6 because each pair was counted twice. The multiplication principle tracks available choices at each step; probabilistic independence is not required.

For a fair die, even has probability 3/6=1/2. Given a result greater than 3, the remaining outcomes are {4,5,6}, so even has probability 2/3. Favorable outcomes divided by all outcomes assumes equal likelihood.

**Worked exercise:** A bag has two red balls and one blue. Drawing two without replacement gives probability (2/3)×(1/2)=1/3 for two reds: after a first red, one of two remaining balls is red. With replacement it becomes (2/3)×(2/3)=4/9. State the assumptions before calculating.
