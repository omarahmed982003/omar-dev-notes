# إعادة تنظيم مسار البداية — 2026-09-27

## ما تغيّر

أصبح مدخل الكارد 17 درسًا بالعربية والإنجليزية، من استخدام النوافذ والماوس والكتابة إلى إنشاء الملفات وحفظها، وفهم الجهاز والبرامج والإنترنت، ثم كتابة أول برنامج وتشغيله وتعديل قيمه وتجربة شرط وحلقة بسيطة.

التطبيق العملي يفترض Windows مع Notepad ومتصفح موجود. يستخدم JavaScript داخل ملف HTML كتجربة أولى دون تثبيت أدوات لغة إضافية، ثم يوجه الطالب لاختيار C++ أو PHP والتعلم من بداية المسار المختار. لا يمثل هذا القسم منهجًا كاملًا لأي لغة، ولا يشترط إنهاء الشبكات والرياضيات المتقدمة قبل كتابة أول برنامج.

- أضيفت خطوات الحفظ وSave As وإظهار الامتدادات والتمييز بين المصدر والتشغيل، مع نتائج متوقعة وأخطاء شائعة وتمارين محلولة.
- اختُصرت موضوعات Git وDebugging والاختبارات إلى الفائدة العامة ومقارنة المتوقع بالفعلي وقراءة خطأ واحد. لا توجد أوامر Git أو فروع أو دمج أو أطر اختبارات في درس البداية.
- حُفظت أجسام الدروس العشرة السابقة في `computer-in-depth` باللغتين، مع توضيح المتطلبات السابقة. تحقق الفحص من وجود النص الأصلي كاملًا في كل نسخة منقولة.
- أصبحت الرياضيات والتحليل والشبكات والتفاصيل الداخلية أقسامًا لاحقة واضحة. أعيد ترتيب الشبكات من التدفق والطبقات والعناوين إلى البروتوكولات والتفاصيل الأعلى.
- حُدّث الكارد وعدّاده والقائمة الجانبية والفهارس وتسلسل السابق/التالي وترتيب صفحة الطباعة. عناوين URL القديمة ما زالت موجودة.
- أضيفت أربعة أمثلة HTML مكتملة في `public/examples/first-program`، وتطابق أمثلة الدروس باللغتين.
