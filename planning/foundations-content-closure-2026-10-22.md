## إقفال الملاحظات

| الملاحظة | ما نُفذ | دليل القبول |
|---|---|---|
| URL: التعريف لا يكفي للبحث العربي | تتبع UTF-8 و percent-encoding، وبناء query عربية بعلامة &، واستعادة القيمة بـ PHP؛ فرق + و%2B، وفك الترميز مرة/مرتين، والـ fragment |8 حالات PHP تشمل العربي والفراغ والصفر والرموز؛ نفس المثال باللغتين |
| NAT/PAT: لا يوجد قبل/بعد عملي | جهازان بنفس منفذ المصدر، جدول ربط داخل/خارج، وتتبّع وجهة الرد وحدود الربط و CGNAT والصلاحيات | مطابقة جدول اللغتين، وجهتا رجوع صحيحتان وربط غير موجود؛ جدول عمودين مناسب للموبايل |
| المتصفح: أسماء بلا تنفيذ | ملف HTML/JavaScript مستقل، خرج A/B/C/D، وتتبع المهمة والـ microtask والمؤقت، والتفاعل والرسم؛ مع async/defer/modules ومقاييس الأداء بمعانيها | تشغيل المثال وتمرينين في Edge، وتجارب محلية مضبوطة لثلاث سياسات تحميل |
| CDN: ملخص بدون رحلة | نموذج نقطتي حضور، MISS/HIT، وتغيير Origin أثناء Freshness ثم التحقق، ومفتاح اللغة وحماية الرد الشخصي والإبطال والفشل | تتبع أزمنة 0/20/30/50/80/310 ومقارنة النسخ والتحقق من فصل مفاتيح اللغات |
| TCP: دعم التعمق بتتبع رقمي | فقد DEF مع وصول GHI، ثم التعويض و ACK المتصل؛ تتبع مستقل وحساب المتاح من النافذتين بعد خصم البيانات القائمة | ACK1003→1003→1009؛ التمرين 2003→2003→2009؛ المتاح 1000 و 1500 بايت في المثالين |

كل درس فيه تمرين مستقل وحل مطوي. الأمثلة تشرح الآلية والحدود بدل إضافة قاموس أدوات. JavaScript مستخدمة في موضوع المتصفح المسمى صراحة؛ بقية تجربة البرمجة الجديدة بـ PHP.

## الصدق في حدود الاختبار

NAT و CDN و TCP هنا **نماذج تعليمية مجهزة** فُحصت حساباتها واتساقها، وليست تجربة راوتر أو CDN حقيقي أوالتقاط حزم. عنوانا IPv4 العامان داخل نموذج NAT مخصصان للتوثيق، ولم تُرسل لهما طلبات. خادم اختبار تحميل JavaScript محلي مؤقت على 127.0.0.1، وأُغلق بعد الاختبار.

اختبارات ترتيب المتصفح لا تثبت عدد مللي ثانية ثابتًا ولا تحسن أداء على كل جهاز. لم تُشغّل كل معامل Node القديمة ولا تجربة GUI للمحرر، ولم نختبر انقطاع الكهرباء. تحذيرات site/sitemap و head-inject القائمة ليست أخطاء بناء جديدة.

## المصادر العلمية القريبة من مواضع الشرح

الدروس نفسها تربط المصادر عند موضوعاتها: PHP لبناء وتحليل query، RFC3022 لترجمة العناوين والمنافذ، RFC2131 لـ DHCP، RFC5737 لعناوين التوثيق، RFC9111 للكاش، MDN و WHATWG لنموذج تنفيذ المتصفح. TCP يحتفظ بمرجعه الرسمي.
