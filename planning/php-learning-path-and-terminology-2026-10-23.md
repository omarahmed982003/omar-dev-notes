## الإصلاحات العلمية والعملية

- إجمالي الطلب يفحص Integer overflow قبل الضرب، ويرفض الأنواع غير المقبولة عند الحد الخارجي.
- AppConfig لا تخفي timeout يساوي `0` أوفراغًا بـDefault؛ الأولوية معلنة بين `$_ENV` وProcess environment. أسماء البيئة تُفحص، وPHP 8.2+/OOP معلنان للمثال. أضيف `examples/php-labs/app-config-check.php` بنفس Class المنشورة، مع تجربة قبول ورفض مستقلة في الحزمة والدوكس، بدل الاعتماد على فحص LESSON_MODE القديم.
- مثال PHPUnit يضم تعريف discount وPHP opening tag وحدود الأرقام، مع فصل مقاطع الأدوات عن إعدادها المطلوب.
- تجربة HTTP محلية مكتملة قبل مقاطع Guzzle والخدمات الوهمية، مع 200/500/304/Timeout.
- معمل FPM يستهدف المنفذ 8080 المعلن في Compose.
- مثال Resilience الذي يعتمد عمليات غير معرفة موسوم Pseudocode، مع رابط للمعمل الفعلي وحدوده.
- Worker Redis صار يحتفظ بالرسالة في Processing list ويسترجع المعلقة عند الرجوع. الأثر التعليمي هو Counter داخل Redis؛ Marker والأثر وAck في Lua واحدة. الرسالة المرفوضة تذهب إلى Dead-letter. أضيفت تجربة Crash بعد Reservation وحدودها في README واللغتين.

معمل Queue **لـWorker واحد فقط**: لا Leases متزامنة، ولا Retry/Backoff للأخطاء المؤقتة في هذا التنفيذ، ولا ضمان بقاء البيانات بعد فقد Redis. إعداد Redis المؤقت وEviction قد يفقدان البيانات؛ لا تدّعي Exactly-once لمزود دفع أو بريد. التنفيذ محدود عمدًا وليس بديلًا عن Queue إنتاجية. أمر BRPOPLPUSH مدعوم لكنه Deprecated، وBLMOVE هو البديل الحديث؛ كلاهما وحده ليس بروتوكولًا مكتملًا. راجع [Redis](https://redis.io/docs/latest/commands/brpoplpush/).

مرجع أولوية تحميل `.env`: [PHP dotenv](https://github.com/phpdotenv/phpdotenv#usage). تحميل `createImmutable` المعتاد لا يعني تعبئة `getenv()` تلقائيًا.

## قاعدة المصطلحات والأساسيات

ثُبتت في `planning/content-writing-guide.md` و`AGENTS.md`: اسم المفهوم بالإنجليزي داخل العربي، والشرح بالمصري؛ أول ظهور يحتاج معنى ووظيفة ومثالًا عند الحاجة، لا ترجمة اسم أوتعريفًا مؤجلًا. الـRuntime ليست مجرد عبارة عربية بديلة؛ شرح مكوناتها منفصل عن استعمال `at runtime` لوصف مرحلة التنفيذ.

مراجعة الأساسيات شملت الصفحات النشطة الـ64: 60 درسًا و4 أدلة. التعديل محدود بأسماء تقنية وصياغة وتعريفات، خصوصًا Software/Runtime وOperating System ومقدمة TCP، من غير إضافة منهج أوتغيير ترتيب أوكود أوالرسومات المعتمدة. أُزيلت إضافات قاموسية آلية مزدحمة خلال المراجعة؛ التعريف الموجود فعلًا لا يُكرر داخل الاسم أوعنوان مركب. صُححت أيضًا بقايا مثل `browserات` واستبدال الصفة العادية «متغيرة» بلفظ Variable خطأً.

الفحص الآلي لا يثبت أن كل مصطلح محتمل مفهوم لكل مبتدئ. تبقى مراجعة السياق البشري إلزامية مع أي تحرير لاحق؛ لا نعتبر قائمة Regex للمصطلحات شهادة اكتمال تعليمية. لم نعد فتح نطاق الأساسيات المعتمد لزيادة عدد موضوعاته.
