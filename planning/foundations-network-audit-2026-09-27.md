# مراجعة أساسيات الكمبيوتر والبرمجة والشبكات
> هذا سجل المراجعة الأولى. التقسيم والتغطية والفحوص الأحدث موثقة في [استكمال الأساسيات والتطبيقات](foundations-practice-update-2026-09-27.md).

تاريخ المراجعة: 27 سبتمبر 2026. المرجع التحريري: [دليل كتابة المحتوى](content-writing-guide.md).

**النتيجة:** تم فحص محتوى الكارد وتحريره على مستوى الدرس، وتصحيح المشكلات المكتشفة، وإضافة الدروس الناقصة، وتشغيل الأمثلة وفحص العرض والتنقل. النطاق الحالي **53 درسًا و5 أدلة أقسام لكل لغة**؛ أي **116 صفحة عربية وإنجليزية**. يشمل البداية، والرياضيات وحل المشكلات، وداخل الكمبيوتر وأدوات التطوير، والشبكات والويب.

## التقييم

| الجانب | قبل المراجعة | ما تغير |
|---|---|---|
| صحة المعلومات | محتوى مفيد، لكنه يحتوي أخطاء محددة وتعميمات تحتاج شروطًا | تصحيح مصافحة TLS وطول رسالة HTTP والقسمة بالسالب والتعقيد والتخزين المؤقت والرسوم؛ اختبار الأمثلة العددية والتنفيذية |
| كثافة المعلومات | مرتفعة في الشبكات والتعمق، وغير متوازنة مع احتياجات البداية؛ فقرات كثيرة تسرد أسماء | تحويل القوائم المختصرة إلى تفسير وتطبيق وحل، وإزالة التمهيد والخلاصة المتكررين بلا فائدة إضافية |
| قوة التغطية | موضوعات متقدمة موجودة، مع فجوة في تمثيل الأرقام وفي القوائم والدوال | درسان عمليان جديدان، وحسابات للذاكرة والعناوين والاحتمال والخوارزميات بدل الاكتفاء بالتعريف |
| طريقة الشرح | تفاوت واضح بين بداية سهلة وفقرات عربية جامدة مخلوطة بمصطلحات كثيرة | تبسيط الصياغة وتعريف المصطلحات في السياق وإعادة كتابة الشهادات ونظام التشغيل والطرفية، وإضافة أمثلة تتدرج من حالة صغيرة إلى الحدود |
| المصطلحات والاختصارات | اختصارات مثل DV/OV/EV لا يُفك اسمها أو معناها، وتعريفات متأخرة أو عامة | الاسم الكامل مع وظيفة مفهومة ومثال عند الحاجة، وتفريق معاني المصطلح حسب السياق؛ مثل IPC في المعالج ونظام التشغيل |
| الترتيب والعناوين | أسماء أقسام فيها عدد الدروس وعبارات تحريرية؛ بداية بعض التمارين تفترض معرفة لم تُشرح | عناوين موضوعية، ومسار متصل بالسابق والتالي، وربط المتطلبات وترتيب الطباعة بنفس ترتيب التعلم |

ده تقييم تحريري مدعوم بأمثلة وفحوص، وليس «نسبة دقة» تستنتج من نجاح البناء. اكتمال المسار هنا مرتبط بأهداف الدروس المنشورة؛ لا يعني تغطية كل تخصصات علوم الكمبيوتر.

## أهم التصحيحات

- **تمثيل البيانات:** شرح 5→101 بطريقتين، و45 و13 و18 و300 بالتحويل العكسي، والفرق بين العدد5 والحرف"5"، والحرف العربي ع في UTF-8، والبكسل والعينة الصوتية والبايت ووحدات الحجم والسرعة. جداول أوزان الثنائي والقسمة تعرض الأرقام بالترتيب الصحيح على الهاتف وفي PDF؛ الفحص البصري كشف انعكاس القسمة بسبب اتجاه العربي وتم إصلاحه.
- **القوائم والدوال:** ملف HTML كامل يعمل في المتصفح، ومدخلات وإرجاع ونطاق ومواضع قائمة، ونتائج54 و90، واختبارات الفارغ والعنصر الواحد والخصم0 و100. المثال يصرح بأنه يستخدم مدخلات ثابتة صالحة ويشرح ما يلزم قبل استقبال مدخلات مستخدم.
- **الشهادات:** DV يتحقق من التحكم باسم الموقع؛ OV يضيف فحص المؤسسة؛ EV له متطلبات تحقق إضافية. الفرق لا يعني تشفيرًا أقوى. شرح CA وسلسلة الثقة والاسم والصلاحية والإلغاء، وتصحيح فصل Certificate عن ServerHello. المراجع داخل [درس الشهادات](../src/content/docs/programming-basics/06-https-tls-certificates.md)، ومنها [مواصفة TLS](https://www.rfc-editor.org/rfc/rfc8446#section-2) و[متطلبات شهادات المواقع](https://cabforum.org/working-groups/server/baseline-requirements/requirements/).
- **HTTP:** جسم الطلب `{"product_id":42,"count":2}` طوله **27 بايتًا** في UTF-8 بلا سطر جديد. صار الرقم محسوبًا في اختبار من نص المثال نفسه. أضيف شرح Safe/Idempotent والحقول والحالات ورفض معاملات الاسم المرسلة كقائمة؛ فحص تعديلات If-Match يتم مع الكتابة لمنع ضياع تحديث. [دلالات HTTP](https://httpwg.org/specs/rfc9110.html).
- **المتصفح والتخزين:** تمييز قراءة الرد عبر CORS عن المصادقة ومنع الطلب؛ شرح الفحص المسبق وحدود no-cors. max-age ليس محصورًا في مخزن المتصفح. شرح إعادة استخدام الاتصال دون استنتاج إصابة المخزن من السرعة وحدها. [دليل CORS](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)، [مواصفة التخزين المؤقت](https://www.rfc-editor.org/rfc/rfc9111).
- **الحساب والخوارزميات:** توضيح اختلاف قسمة الأعداد السالبة بين اللغات، وعدم اشتراط الاستقلال الاحتمالي لمبدأ العد، ومتوسط كلفة البحث في Hash map مقابل أسوأ حالة، وأمثلة للجشع والبرمجة الديناميكية والتتبع. [قواعد القسمة في Python](https://docs.python.org/3/library/stdtypes.html#numeric-types-int-float-complex).
- **الطرفية والذاكرة:** أمثلة في مجلد تدريب يجهزه المتعلم، وتمرير كائنات PowerShell، وفصل stdout وstderr ورمز الانتهاء، وترجمة عنوان افتراضي إلى صفحة وإزاحة. [أنابيب PowerShell](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_pipelines).
- **التنظيم:** إزالة الأعداد من أسماء الأقسام والعناوين التحريرية، وتوحيد العناوين في الكارد والفهرس والشريط والتنقل والطباعة. عدد دروس الكارد يحسب جميع دروسه ويستبعد أدلة الأقسام.

## أدلة التحقق

| الفحص | النتيجة |
|---|---|
| المحتوى والروابط | 116 صفحة، و186 رابط محتوى داخلي، و204 روابط سابق/تالٍ؛ لا رابط مفقود في الفحص |
| أمثلة البداية | 31 فحص تشغيل في المتصفح ومطابقة كود الدروس العربية والإنجليزية مع ملفات الأمثلة |
| PHP | 12 مقطعًا اجتاز فحص الصياغة، و12 طلب HTTP فعليًا: اسم عادي، افتراضي، مسافات، قائمة مرفوضة، POST مرفوض، وبايت غير صالح |
| الطرفية وGit | نجحت الكتابة والقراءة واختيار حقول الملفات وفصل قنوات الخرج ورمز3 المتعمد، وإنشاء مستودع ولقطة وتعديل محلي؛ عُطّل التوقيع في بيئة اختبار اللقطة |
| عرض الموقع | 118 صفحة شاملة الرئيسيّتين؛ محتوى وصور موجودة، ولا أخطاء JavaScript أو شاشة خطأ؛ 8 فحوص هاتف ونجاح الانتقال الفعلي مرتين |
| العرض البصري | معاينة الصفحة الرئيسية وجدول الشهادات على سطح المكتب والهاتف، وجدول الثنائي ورسم الحلقة على الهاتف |
| بناء الموقع | بناء ناجح؛ التحذيرات العامة: توجيه head-inject في صفحتي MDX، ومدخل404 غير موجود، وعدم إعداد site لخريطة الموقع |
| نسخة PDF | 1087 صفحة من 308 مستندات الموقع؛ تصدير 14 قسمًا والغلاف، ودمجها بترقيم متصل وفهرس جانبي. فحص وجود الدروس الجديدة ونهاية الإنجليزية، ومعاينة صفحات عربية وإنجليزية. نسخة التنزيل مطابقة للملف الناتج |

ملفات الفحص القابلة للإعادة: [المحتوى](../scripts/verify-foundations-content.mjs)، [أمثلة البداية](../scripts/verify-beginner-path.mjs)، [PHP](../scripts/verify-foundations-php.mjs)، [المتصفح](../scripts/verify-foundations-browser.mjs). يحتاج فحص المتصفح خادم الموقع المحلي؛ يحتاج فحص PHP مفسّر PHP. [فحص اتجاه الأرقام](../scripts/verify-binary-layout.mjs) يتحقق من ترتيب رموز القسمة وأوزان الخانات على سطح المكتب والهاتف، و[فحص PDF](../scripts/verify-docs-pdf.py) يتحقق من اكتمال الأقسام ووجود أمثلة الدروس في الملف.

لتحديث PDF: شغّل `npm run dev -- --background`، ثم `npm run docs:pdf`، ثم `npm run build` لتحديث ملف التنزيل في البناء. يحتاج التصدير متصفح Chromium وPython مع `pypdf` و`reportlab`؛ يكتشف بيئة Codex المرفقة تلقائيًا، ويمكن تحديد مساري الأداتين عبر `PLAYWRIGHT_BROWSER_PATH` و`PYTHON_BINARY`. التصدير ينتظر اكتمال قراءة HTML ويطابق عدد المستندات قبل قبول الناتج.

النتائج الآلية في [مجلد الأدلة](audit-results/). نجاحها يثبت الحالات المختبرة، ولا يحل محل المراجعة التحريرية. لم تُختبر كل بيئات الشبكات والمتصفحات الخارجية؛ أمثلة القياس التي تعتمد على موقع خارجي توضح أن القيم تتغير، والمقاطع الجزئية موصوفة بصفتها مقاطع.

## إعادة تصدير PDF

يستخدم أمر npm run docs:pdf متصفح Chromium مثبتًا وPython مع pypdf وreportlab. يكتشف أدوات بيئة Codex المرفقة تلقائيًا، أو يمكن تحديد PYTHON_BINARY وPLAYWRIGHT_BROWSER_PATH. عنوان الطباعة الافتراضي http://localhost:4321/print/all/ ويمكن تغييره بـDOCS_PRINT_URL. ملفات التجزئة المؤقتة تزال بعد الدمج. فحص scripts/verify-docs-pdf.py يتحقق من الأقسام والصفحات ووجود الدروس الجديدة ووصول المحتوى إلى آخر قسم إنجليزي.


سبب نقص PDF كان بدء الطباعة عند هدوء الشبكة بينما المتصفح ما زال يقرأ صفحة الطباعة الطويلة. التصدير الآن ينتظر اكتمال تحميل الصفحة، وعلامة نهايتها، ومطابقة عدد الدروس المعروضة بالعدد المتوقع، ثم يتحقق من مجموع المستندات في الأجزاء قبل الدمج. غلاف الكتاب وأعداد أقسامه تُحسب من المحتوى الحالي بدل الرقم105 الثابت القديم.
